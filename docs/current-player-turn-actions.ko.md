# 플레이어 턴 행동 기획서 — 현재 구현 기준

- 기준일: 2026-10-20
- 대상: MechaXCOM 전투 프로토타입
- 목적: 현재 플레이어가 수행할 수 있는 행동, 비용, 조작 흐름과 제한을 정리한다.
- 문서의 수치는 기본값과 샘플 무기 기준이다. 씬의 Inspector 설정과 장착 WeaponData가 실제 적용값을 결정한다.
- 향후 기능 제안이 아닌 현재 코드의 동작을 기록한 문서다.

## 1. 턴 구조와 행동 자원

플레이어 진영 턴 → 적 진영 턴 → 다음 플레이어 진영 턴을 반복한다.

플레이어 진영 턴에는 행동 가능한 아군 기체를 원하는 순서로 선택한다. 한 기체의 행동을 모두 끝내고 다음 기체로 넘어갈 필요는 없다. 다만 다른 기체의 이동이나 이동 후 방향 확정이 진행 중일 때는 전투 행동과 기체 전환이 제한된다.

- AP는 기체마다 독립적으로 관리한다.
- 기본 최대 AP는 기체당 5다.
- 자신의 진영 턴이 시작될 때 해당 진영 기체의 AP가 최대치로 회복된다.
- 남은 AP를 다음 턴에 더해 저장하지 않는다.
- 행동 순서는 고정하지 않는다. 남은 AP와 기체 상태가 허용하면 이동 후 공격, 공격 후 이동, 여러 번 이동 등이 가능하다.
- 공격 횟수의 별도 상한은 없다. 현재 기본 공격 비용이 AP 3이므로 기본 AP 5에서는 보통 한 번 공격한다.

## 2. 행동 목록

| 행동 | AP 비용 | 조작 및 결과 |
|---|---:|---|
| 아군 기체 선택·전환 | 0 | 마우스 왼쪽 클릭으로 선택하고 해당 기체의 행동 메뉴를 표시한다. |
| 이동 | 이동 경로 1칸당 1 | Move → 도착 칸 선택 → 경로를 따라 이동한다. |
| 이동 후 방향 확정 | 0 | 동·서·남·북 중 방향을 선택하고 Confirm으로 확정한다. |
| 공격 무기 선택 | 0 | Attack → 장착한 무기의 손 위치와 이름을 선택한다. |
| 적·부위 조준 및 미리보기 | 0 | 적 선택 후 명중률·예상 피해 범위·AP 비용을 확인한다. 원거리 공격만 부위 조준이 가능하다. |
| 공격 확정 | 무기별 지정값 | Fire 또는 근접 Strike로 확정한다. 빗나가도 AP를 소비한다. |
| 경계 준비 | 0 | Overwatch → 원거리 무기 → 4방향 선택. 주황색 감시 칸을 확인한다. |
| 경계 확정 | 2 | Confirm으로 확정. 이동하는 적에 몸통 1회, 명중률 ×0.75로 반응한다. 발사 추가 AP는 없다. |
| 긴급탈출 | 1 | Eject로 기체를 이탈한다. 해당 기체는 이번 전투에서 더 이상 사용할 수 없다. |
| 선택 취소 | 0 | ESC로 기체 선택과 조준을 해제한다. 이미 실행한 행동은 되돌리지 않는다. |
| 진영 턴 종료 | 별도 소비 없음 | End Turn으로 남은 AP에 관계없이 적 진영 턴으로 넘긴다. |

## 3. 이동

### 3.1 조작 흐름

기체 선택 → Move → 이동 가능 범위 표시 → 도착 칸 클릭 → 이동 → 도착 방향 선택 → Confirm.

- 그리드의 상·하·좌·우로 이동한다. 대각선으로 직접 한 칸 이동하지 않는다.
- 목적지까지 실제 이동한 경로 길이만큼 AP를 소비한다.
- 장애물, 골짜기 등 이동 불가 지형과 다른 유닛이 점유한 칸은 통과하거나 도착할 수 없다.
- 이동 중에는 모델이 진행 방향을 바라보고 전진한다.
- 이동 취소 입력으로 이미 이동한 거리나 사용한 AP를 되돌릴 수 없다.
- ESC로 선택을 해제해도 진행 중인 이동은 계속된다. 정상 도착 후 방향 선택 단계가 열린다.

### 3.2 이동 가능 거리

한 번의 이동 명령에서 이동 가능한 거리는 다음 두 값 중 작은 값이다.

```text
다리 손상을 반영한 이동 범위
남아 있는 AP
```

기본 이동 범위와 AP가 모두 5라면, AP 5로 최대 5칸 이동한다. AP가 2 남았다면 최대 2칸 이동한다.

- 한쪽 다리 파괴: 기본 이동 범위를 절반으로 내림 처리한다. 원래 이동 범위가 양수라면 최소 1칸이다. 기본 5일 때 한 번에 최대 2칸이다.
- 양쪽 다리 파괴: 이동할 수 없다.
- 현재 이동 범위는 **이동 명령마다 적용하는 상한**이다. 별도의 턴 전체 이동 거리 예산은 없다. 예를 들어 한쪽 다리가 파괴되어 범위 2인 기체도 AP 5가 있으면 2칸 → 2칸 → 1칸으로 나눠 이동할 수 있다.

### 3.3 이동 기록

이동 거리와 기존 기동 회피 값은 UnitMobility에 기록하지만, 목표 기동 회피는 현재 명중률 계산과 UI에서 제외했다. 이동을 많이 했다는 이유로 공격 명중률이 감소하지 않는다.

## 4. 이동 후 방향 선택

- 방향은 북(+Z), 동(+X), 남(-Z), 서(-X) 네 방향이다.
- 선택한 방향은 Confirm을 눌렀을 때 반영된다.
- AP가 0이어도 이동 후 방향을 확정할 수 있다.
- 방향 선택 중에는 다른 전투 행동과 턴 종료가 제한된다.
- 방향 선택 대기 중 ESC를 누르면 도착 당시 방향을 유지하고 선택을 해제한다.
- 방향 확정 회전이 이미 시작됐다면 ESC로 회전을 중단하지 않는다.
- 현재 바라보는 방향에 따른 부위 노출·명중률 보정은 적용하지 않는다.

## 5. 공격

### 5.1 공통 흐름

```text
기체 선택
→ Attack
→ 장착 무기 선택
→ 발견한 적 선택
→ 명중률·피해 범위·AP 비용 확인
→ Fire 또는 Strike로 확정
→ 결과 반영 후 기본 행동 메뉴로 복귀
```

- 오른손·왼손의 장착 무기를 공격 종류 구분 없이 한 목록에 표시한다.
- 한손 무기는 Right/Left와 무기 이름을 표시한다.
- 실제 양손 파지 무기는 Both hands와 무기 이름으로 한 번만 표시한다.
- 빈손은 목록에서 생략한다. 같은 무기 에셋을 양손에 한손씩 장착했다면 두 자루로 구분한다.
- 무기가 하나여도 직접 선택해야 공격 모드에 들어간다.
- 무기 선택과 조준은 AP를 소비하지 않으며, 두 손의 무기 중 공격 수단을 고르는 추가 AP 비용도 없다.
- AP가 부족한 무기는 목록에 표시하되 선택할 수 없다. 사용할 수 있는 공격이 전혀 없다면 Attack을 시작할 수 없다.
- 장착 설정이 없거나 비어 있으면 비무장이다. 잘못된 장착 설정도 공격할 수 없다.

### 5.2 일반 공격 가능 조건

- 플레이어 진영 턴이어야 한다.
- 공격자는 행동 가능한 상태여야 하고, 이동·방향 확정이 진행 중이면 안 된다.
- 선택 무기를 사용할 AP가 있어야 한다.
- 표적은 발견된 적 기체여야 한다.
- 무기 사거리 안에 있어야 한다. 거리는 가로 칸수와 세로 칸수를 합산한다.
- 원거리 공격은 건물 등에 사선이 막히면 사용할 수 없다.
- 근접 공격은 실제로 근접 접촉이 가능한 경로 조건을 만족해야 한다. 골짜기 너머를 거리만으로 타격하지 않는다.

발견된 적을 선택해도 사거리·사선 등의 조건이 맞지 않으면 공격 미리보기에 사유를 표시하고 확정할 수 없다.

### 5.3 원거리 공격

- 적을 선택한 후 몸통, 콕피트, 머리, 좌·우 팔, 좌·우 다리를 조준할 수 있다.
- 최초 기본 조준은 몸통이다.
- 부위를 변경하면 해당 부위 명중률과 HP를 확인할 수 있다.
- 명중률에는 무기 성능, 파지, 거리, 공격자 머리 손상, 조준 부위와 방향별 엄폐 등이 반영된다.
- 공격이 명중하면 선택 부위에 무기의 최소~최대 피해 중 정수 피해를 적용한다. 빗나가면 피해가 없지만 AP는 소비한다.
- 아직 탄약 소비는 구현하지 않았다.

### 5.4 근접 공격

- 선택 무기의 근접 사거리와 접근 가능 조건을 사용한다.
- 부위를 직접 조준하지 않고 몸통을 공격한다.
- 엄폐와 부위 조준에 의한 명중률 감소는 적용하지 않는다.
- 공격자의 머리 손상 보정은 적용된다.
- 원거리와 마찬가지로 명중 시 무기 피해 범위 안에서 피해를 결정한다.

### 5.5 현재 샘플 무기

| 무기 | 공격 종류 | AP | 사거리 | 피해 |
|---|---|---:|---:|---:|
| StandardRifle | 원거리 | 3 | 7칸 | 4~6 |
| StandardBlade | 근접 | 3 | 2칸 | 7~9 |
| MS115Rifle | 원거리·양손 필수 | 5 | 10칸 | 3~9 |

1V1Test의 고정 피해 무기는 별도 Defaults 에셋을 사용한다. 실제 기체의 장착 데이터가 위 예시와 다를 수 있다.

### 5.6 경계사격

Overwatch → 원거리 무기 선택 → 4방향 선택 → Confirm으로 AP 2를 소비한다. 전방 90도와 무기 사거리, 사수 개인 시야·사선을 만족하는 적이 한 칸 이동을 마칠 때 몸통을 한 번 사격한다. 명중률은 ×0.75이며 발사 AP는 추가 소비하지 않는다. 빗나가도 경계를 소모한다.

경계 중 일반 이동·공격은 제한하지만 AP가 있으면 탈출할 수 있다. 확정 후 ESC는 선택만 해제한다. 다음 자기 진영 턴 시작 시 AP 회복 전에 만료하며, 무기 변경·전투불능·비활성화·전투 종료 등에도 취소한다. 자세한 흐름은 [경계사격 안내](overwatch-guide.ko.md)를 참고한다.

## 6. 긴급탈출

- Eject에 AP 1을 소비한다.
- 정상 Active 상태와 Critical 상태에서 사용할 수 있다.
- 플레이어 턴이어야 하며, 이동·방향 확정 중이거나 AP가 부족하면 사용할 수 없다.
- 탈출한 기체는 Ejected 상태가 되어 그리드 점유와 표시가 해제되며, 해당 전투에서 재사용할 수 없다.
- 탈출은 소대 전체 철수와 다른 행동이다.
- CharacterData는 정의되어 있지만 탈출 후 생존·부상·사망 결과와 다음 임무 복귀에는 아직 연결하지 않았다.

## 7. 기체 상태에 따른 행동 제한

| 상태 | 이동 | 공격 | 긴급탈출 |
|---|---|---|---|
| Active | AP·다리 상태에 따라 가능 | AP·무기·조준 조건에 따라 가능 | AP 1로 가능 |
| Critical | 불가 | 불가 | AP 1로 가능 |
| Destroyed | 불가 | 불가 | 불가 |
| Ejected | 불가 | 불가 | 이미 탈출한 상태 |

경계는 별도 MechState가 아니다. Active 상태여도 경계 중에는 이동·공격이 제한되고, 남은 AP로 긴급탈출할 수 있다.

머리 파괴 시 기본 공격 명중 배율은 ×0.75다. 팔 파괴에 따른 무기 사용 제한은 아직 없다. 한쪽 다리·양쪽 다리 파괴는 앞서 정리한 이동 제한을 적용한다.

Critical은 그리드에 남아 있는 상태이며, Critical 상태인 기체가 남아 있다는 이유만으로 해당 진영의 전투 종료가 확정되지는 않는다.

## 8. 턴 종료와 남은 AP

- End Turn은 아군 진영 전체의 턴을 종료한다.
- AP를 남긴 채 종료할 수 있다. AP가 남았다고 별도 방어 보너스를 받지는 않는다.
- 모든 아군 AP를 소진해도 자동으로 턴을 종료하지 않는다.
- 이동이나 방향 확정, 반응 사격 처리가 진행 중일 때는 턴을 종료할 수 없다.
- 적들이 순서대로 행동한 뒤 다음 플레이어 턴으로 넘어간다.

## 9. AP 조합 예시

기체가 Active이고 기본 AP 5, 충분한 이동 범위와 공격 조건을 갖춘 상황이다.

| 행동 순서 | 총 AP | 남은 AP |
|---|---:|---:|
| 2칸 이동 → 방향 확정 → StandardRifle 공격 | 5 | 0 |
| StandardRifle 공격 → 2칸 이동 → 방향 확정 | 5 | 0 |
| 1칸 이동 → 방향 확정 → 1칸 이동 → 방향 확정 → StandardBlade 공격 | 5 | 0 |
| 4칸 이동 → 방향 확정 → 긴급탈출 | 5 | 0 |
| MS115Rifle 공격 | 5 | 0 |
| 3칸 이동 → 방향 확정 → 경계 | 5 | 0 |
| StandardRifle 공격 → 경계 | 5 | 0 |
| 아무 행동 없이 End Turn | 0 | 남은 AP를 넘겨 저장하지 않음 |

## 10. AP를 사용하지 않는 화면 조작

| 조작 | 기능 |
|---|---|
| 아군 기체 왼쪽 클릭 | 기체 선택 |
| 아군 기체 더블클릭 | 해당 기체가 화면 중심에 오도록 카메라 이동 |
| ESC | 선택·조준 해제. 이동 후 방향 선택 중이면 도착 방향 유지 |
| WASD | 카메라 평행 이동 |
| Q / E | 카메라를 반대 방향으로 90도씩 부드럽게 회전 |
| 마우스 휠 | 줌인·줌아웃 |

## 11. 아직 행동으로 제공하지 않는 기능

대기·방어 보너스 행동, 반격·기회공격, 재장전·탄약 관리, 전투 중 무기 교체·수납·파지 전환, 부스트, 수리·회복, 소대 전체 철수는 현재 플레이어 행동으로 구현하지 않았다.

파일럿 능력치·패시브의 전투 보정은 아직 연결하지 않았다. MechaData의 최대 HP·기본 AP는 사용하며, 현재 명중률은 무기·상태·경계 보정을 사용한다.
