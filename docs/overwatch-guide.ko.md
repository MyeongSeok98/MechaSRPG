# 경계사격 사용 안내

## 조작

1. 플레이어 기체를 선택하고 **Overwatch / AP 2**를 누른다.
2. 사용할 원거리 무기를 선택한다. 한 자루여도 직접 선택하며, 양손 무기는 한 번만 표시한다.
3. 북·동·남·서 중 방향을 선택한다. 주황색 칸으로 감시 범위를 확인한다.
4. **Confirm / AP 2**를 누르면 AP 2를 소비하고 `OVERWATCH` 상태가 된다.
5. 턴을 종료하면 감시 조건을 만족하는 적의 이동에 반응해 자동 사격한다.

확정 전에는 AP를 소비하지 않는다. 준비 중 ESC는 선택과 준비를 취소한다. 확정 후 ESC는 선택만 해제하며 이미 시작한 경계를 취소하지 않는다.

## 발동 조건

- 선택 방향의 전방 90도, 즉 좌우 45도 안을 감시한다. 경계선도 포함한다.
- 무기 사거리, **사수 개인의 탐지 거리**, 건물에 의한 시야·사선 차단 조건을 모두 만족해야 한다. 다른 아군이 발견했어도 사수 개인 시야 밖이면 사격하지 않는다.
- 무기 사거리는 가로·세로 거리의 합이고, 개인 탐지 거리는 원형이다. 두 범위와 부채꼴의 교집합을 감시한다.
- 적이 한 칸 이동을 완료하여 점유·이동 AP·이동 거리 기록이 갱신된 뒤 판정한다.
- 처음부터 감시 범위 안에 있던 적도 이동하면 발동한다. 경계 진입 시점, 정지, 회전이나 일반 공격만으로는 발동하지 않는다.
- 한 번의 경계에서 **몸통에 한 발** 쏜다. 명중과 빗나감 모두 경계를 소모한다. 조건이 맞지 않아 발사하지 않았다면 경계를 유지한다.

## 명중률과 AP

```text
무기 기본 명중률 × 파지 × 거리 × 사수 머리 손상 × 몸통 보정 × 엄폐 × 0.75
→ 0~100 제한 → 마지막에 한 번 반올림
```

경계 진입 비용은 무기의 일반 공격 AP와 관계없이 2다. 일반 공격에 AP 5가 필요한 무기도 AP 2로 경계를 시작할 수 있다. 반응 사격 시 AP를 추가 소비하지 않는다. 무기 피해 범위는 일반 공격과 같다.

목표의 기동 회피는 일반 공격과 경계사격 모두 명중률에서 제외했다. 이동 거리 기록은 남아 있다. 파일럿 능력치·패시브는 아직 이 계산에 연결하지 않았고, 탄약 소비도 아직 구현하지 않았다.

## 행동 제한과 만료

- 경계 중에는 일반 이동·공격·경계 재설정이 제한된다. 남은 AP는 유지하며, 조건과 AP 1을 충족하면 긴급탈출할 수 있다.
- 발사하지 않았어도 **다음 자기 진영 턴 시작 시 AP 회복 전에 만료**한다. 비용은 환급하지 않는다.
- 무기 장착 변경, 기체의 전투불능·탈출·비활성화, 전투 종료 등으로 유효하지 않게 되면 취소한다. 무기를 원래대로 돌리거나 서비스를 다시 켜도 이전 경계가 복원되지 않는다.
- 여러 기체가 반응하면 전투에 등록된 순서로 처리한다. 앞선 사격으로 표적이 파괴되면 나머지는 발사하지 않는다. 전투가 계속 중이면 미사용 경계를 유지한다. Critical 표적에는 남은 사수가 추가 사격할 수 있다.
- 피격 후 이동 가능한 생존자는 경로를 계속 이동한다. Critical·파괴·탈출 또는 양 다리 파괴 등으로 이동할 수 없으면 중단한다. 이미 이동한 칸의 AP는 환급하지 않는다.

현재 적 AI는 기존 이동·공격을 수행하며 스스로 경계에 진입하지 않는다. 반응 사격의 결과 적용은 즉시 처리하며 별도 사격 연출은 없다.

## 코드와 샘플 씬

`BattleSceneController`가 기존 `1V1Test`, `SqurdWeaponTest`에서 `OverwatchSystem`을 런타임에 연결한다. 씬이나 프리팹에 새 컴포넌트를 직접 추가할 필요가 없다.

| 담당 | 코드 |
|---|---|
| 경계 무기·방향·유효 상태 | `Scripts/Unit/UnitOverwatch.cs` |
| 진입 비용·범위·이동 반응 순서 | `Scripts/Combat/OverwatchSystem.cs` |
| 전방 부채꼴 판정 | `Scripts/Combat/OverwatchMath.cs` |
| 일반·반응 공통 명중/피해 | `Scripts/Combat/CombatSystem.cs`, `CombatMath.cs` |
| 칸 완료 후 반응 대기·이동 재검사 | `Scripts/Unit/UnitMovement.cs` |
| 다음 자기 턴 만료·전투 종료 정리 | `Scripts/Turn/TurnManager.cs` |
| 무기/방향 선택·주황색 범위 | `Scripts/Input/PlayerInputController.cs`, `Scripts/Presentation/` |

코드 경로는 `Assets/_Game/` 기준이다. `OverwatchSceneTests`는 두 저장 씬의 연결과 메뉴 확정, 실제 적 AI의 이동·반응·행동 재개·턴 전환 및 취소 상태를 검증한다. 범위·명중 계산, 다중 사수, Critical, 이동 중단, 실제 마우스 조작은 나머지 `Overwatch*Tests`에서 검증한다. 원본 씬 배치와 사용자 조정 속도는 변경하지 않는다.
