# 기체 정보와 선택 표시

평소에 아군 또는 현재 탐지한 적을 왼쪽 클릭하면 선택합니다. 선택된 기체의 바닥에는 **아군은 초록색, 적은 빨간색 외곽선 사각형**이 표시됩니다.

기본 화면에서는 [선택 기체 정보 패널](selected-unit-info-panel.ko.md)에 이름·초상화·AP·상태·동적 부위 HP를 표시합니다. F3로 여는 상세 디버그창에서는 다음을 확인할 수 있습니다. 정보가 길면 창 안에서 스크롤합니다.

- **기체명:** MechaData의 표시 이름. 기체 데이터가 없는 테스트 유닛은 씬 오브젝트 이름.
- **파일럿 초상화:** 선택한 기체의 CharacterData.DefaultPortrait를 표시합니다. 파일럿 또는 Default 이미지가 없으면 샘플 초상화를 사용합니다. 원래 이미지 비율을 유지합니다.
- **부위 HP:** 현재/최대 HP와 AP, 기체 상태. Head / Body / L.Arm / R.arm / L.Leg / R.Leg / C.Pit를 사용.
- **장착 무기:** 왼손·오른손 무기 이름과 백팩·백팩 무장. 양손 파지는 Both hands로 한 번 표시하며 빈 슬롯은 None.

적 선택은 정보 확인용입니다. 적의 이동·공격·재장전·경계·탈출을 실행할 수 없으며 적 턴에도 같습니다. 아군을 다시 클릭하면 기존 행동 메뉴를 사용할 수 있습니다.

아군의 공격 무기를 이미 선택한 상태에서 적을 클릭하면 기존처럼 **공격 대상 지정**으로 처리합니다. 이때 행동할 아군의 선택과 초록 테두리는 유지됩니다. 곡사 무기는 기존 좌표 조준을 유지합니다.

ESC 또는 허공 클릭으로 선택을 해제합니다. 적이 시야에서 사라지거나 파괴되면 정보와 선택 테두리도 사라집니다. 미탐지 적을 클릭해서 정보를 볼 수는 없습니다. 다른 유닛의 이동·방향 확정·팝업·경계 결정 중에는 기존 선택 제한을 유지합니다.

1V1Test·SqurdWeaponTest·EliminationMissionTest·DestroyCommunicationStationTest에 기본 샘플 초상화를 연결했습니다. 각 씬의 BattleDebugUI에 기본 초상화 참조만 추가하고 기존 설정·배치는 유지합니다. 기존 적 행동 표시용 빨간 테두리도 유지합니다.

## 구현 연결

PlayerInputController가 선택과 아군 행동 권한을 구분하고, 기존 BattleDebugUI가 UnitInspectionText로 이름/HP/장착 정보를 읽습니다. BattleDebugUI.PilotPortrait는 표시 가능한 선택 유닛의 PilotData.DefaultPortrait를 우선 사용하고, 없으면 Inspector의 **기본 파일럿 초상화**를 사용합니다. 이것도 없으면 Portrait unavailable을 표시합니다. Sprite의 UV 범위와 가로세로 비율을 유지하며 기체를 별도 렌더링하지 않습니다.

GridVisualizer는 기존 재질을 복사한 런타임 재질로 선택 색상을 적용합니다. 초상화는 공유 Sprite를 참조하며 선택 전환이나 창 비활성화 시 원본 이미지를 변경하거나 파괴하지 않습니다. Laugh/Damaged 전환은 아직 연결하지 않았습니다. 이미지 정의는 [파일럿 초상화 연결](character-portraits.ko.md)을 참고하세요.

검증 기록은 Artifacts/PilotPortraitHUDVerification에 보관합니다. 선택 파일럿 우선·미지정/누락 대체·선택 전환·비활성화·시야 상실 보호와 실제 Sprite 위아래 방향, 네 저장 씬의 기본 초상화 연결을 확인합니다.

2026-11-10: 관련 EditMode32/32·그래픽 PlayMode8/8 통과. 실제 캡처에서 Sprite 범위 밖 픽셀 제외·4:5 비율·위아래 방향을 확인했습니다. 네 씬의 기본 초상화 참조 추가 외에 기존 씬 설정·배치와 기체/파일럿/무기/이미지 데이터는 유지했습니다.
