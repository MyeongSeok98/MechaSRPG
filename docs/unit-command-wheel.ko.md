# 아군 선택 행동 메뉴

아군을 클릭하면 선택 링이 회전하며 나타나고, 약0.44초 뒤부터 선과 글자가 함께 표시됩니다. AP 문구까지 약0.83초 안에 완성됩니다. 시간은 Time.unscaledTime을 사용합니다.

- 왼쪽 위 Move / 오른쪽 위 Attack
- 왼쪽 아래 Overwatch / AP 2 / 오른쪽 아래 Eject / AP 1
- 아래 중앙 Reload: 기존 재장전 무기 선택 기능 유지
- 선택한 행동: 초록색 외곽과 회색 내부
- 사용할 수 없는 행동: 어두운 글자. 실제 허용 여부와 AP 소모는 기존 입력/전투 규칙을 따릅니다.

이동 또는 공격 조준 중에도 선택한 행동이 보입니다. 버튼/보조창만 클릭을 소비하고 원 중앙과 선 사이의 빈 공간은 맵 클릭을 통과시킵니다. ESC, 적 정보 보기, 적 턴/턴 배너/임무 종료/이동 중 잠금은 기존 입력 규칙을 따릅니다. 같은 기체를 다시 선택하면 애니메이션이 다시 시작하고, AP 변화나 행동 전환만으로는 재시작하지 않습니다.

무기 선택창·방향 선택·대상 공격 확정창은 기존 흐름을 유지합니다. 대상/시설/곡사 착탄점이 확정된 조준 화면에서는 작은 기존 세부 패널을 사용합니다. HUD 또는 화면 경계와 겹치면 행동 버튼의 배치 영역만 이동하며, 보조 무기창은 양옆 또는 위아래의 빈 위치를 찾습니다.

선택 원의 중심은 버튼 배치와 분리되어 항상 현재 카메라가 투영한 기체 몸체 가운데를 따라갑니다. 모델의 Mesh/SkinnedMesh Renderer 높이 가운데와 유닛 루트 X/Z를 사용해 무장이 옆으로 돌출되어도 가로 중심이 밀리지 않게 합니다. 모델이 없으면 기존 Renderer/Collider/루트 위치로 대체합니다. 연결선은 고정된 원 가장자리에서 이동한 버튼 쪽으로 이어집니다. 화면 끝에서 원 일부가 잘릴 수는 있지만 이를 피하려고 원 중심을 옮기거나 카메라를 이동하지 않습니다.

UnitActionUI의 Selection Animation Speed, Command Color, Selected Command Fill을 Inspector에서 조절할 수 있습니다. 기존 Battle Systems의 PlayerInputController 초기화가 UnitActionUI를 생성/재사용하므로 각 씬을 다시 저장할 필요는 없습니다. 재생 전부터 값을 지정하려면 같은 오브젝트에 UnitActionUI를 추가해 설정할 수 있습니다. 기체·무기 데이터 및 카메라 설정은 변경하지 않았습니다.

현재는 전투기 HUD 시안3(시안2의 세부 동작 + 글자 Outer Glow)을 사용합니다. 눈금 점등·정렬 가이드 수렴·역회전 보조 링·브래킷·스캔·연결선 선단·타이핑 커서가 나타나고, 네 행동 채널을 차례로 확인한 뒤 약1.38초에 확정됩니다. 이후 계속 회전하거나 점멸하지 않습니다. 원 주변 장식은 모두 고정된 기체 중심을 따르고, 행동 끝의 표시만 이동한 버튼 위치를 따릅니다.

글자는 단색 초록색을 유지하면서 저투명도 글자 외곽을 여러 방향으로 겹쳐 부드러운 발광을 더합니다. UnitActionUI의 **글자 외곽 발광 강도**(기본1, 0이면 끔)와 **글자 외곽 발광 반경**(기본6, 메뉴 배율 적용)으로 조절합니다. 사용 불가 글자는 발광도 함께 약해집니다. 선택한 행동의 초록 외곽/회색 내부와 기존 클릭 영역은 유지하며, 그라데이션이나 새 패키지는 추가하지 않았습니다. 시안의 가상 기체명·데모 상태 문구·재생 버튼은 실제 전투 화면에 넣지 않습니다.

표시 책임: CommandWheelAnimation(시간) → UnitCommandWheel(링/선/글자·선택 배경·기하 배치) → UnitActionUI(기존 명령·클릭 연동). PlayerInputController는 성공한 선택을 알려줄 뿐 전투 계산을 변경하지 않습니다.

CommandWheelHud는 눈금·브래킷·보조 링·채널 잠금 등 장식만 그립니다. 별도 입력이나 전투 상태를 만들지 않습니다.

인광 화면 시안 적용: 글자 중심색을 약간 밝히고 기존 Outer Glow를 유지합니다. 링·선·장식에는 최대 네 개의 과거 애니메이션 상태를 약하게 겹쳐 짧은 잔광을 만듭니다. 과거 화면 좌표를 저장하지 않고 현재 기체 중심/버튼 배치로 다시 그리므로 카메라 이동 후 화면에 잔상이 남지 않습니다. 선택 해제 시 별도 잔광 버퍼도 남지 않습니다. 글자는 복제하지 않아 읽기 쉽게 유지하고 글리프 안에만 옅은 주사선을 더합니다. 기하 도형에는 반복 래스터로 약한 주사선/입자 질감을 넣습니다. 월드·초상화·다른 패널에는 적용하지 않습니다.

UnitActionUI Inspector의 **인광 잔광 시간 (초)**는 기본0.12(0이면 끔), **인광 주사선·입자 강도**는 기본0.04(0이면 끔)입니다. 약1.38초에 확정되는 기존 연출은 유지하고 잔광 꼬리는 최대0.6초 뒤 사라집니다. 이는 시안의 화면 누적 방식을 IMGUI에 맞춰 최대 네 개의 과거 기하 상태로 근사한 효과입니다. 지속 회전·점멸이나 전체 화면 CRT 필터는 추가하지 않습니다.
