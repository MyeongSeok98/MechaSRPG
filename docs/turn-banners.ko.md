# 턴 시작 배너

플레이어 턴에는 **YourTurn.png**, 적 턴에는 **EnemyTurn.png**를 화면 중앙에 표시합니다. 전투를 처음 시작할 때도 플레이어 배너가 나옵니다.

기본 순서는 **오른쪽 밖에서 0.15초 진입 → 중앙에서 0.4초 정지 → 왼쪽으로 0.15초 퇴장하며 페이드아웃**입니다. 이미지 비율을 유지하고 화면 너비의 약 90%로 표시합니다. 실제 시간 기준으로 동작하며 게임 시간 배율을 바꾸지 않습니다.

배너 동안에는 다음 조작을 막습니다.

- 기체 선택·조준·이동·공격·재장전·경계·탈출·턴 종료
- ESC 선택 해제와 더블클릭 초점 이동
- WASD 이동·Q/E 회전·휠 줌을 포함한 카메라 조작
- 정보창 버튼·스크롤 입력

적 AI는 적 턴 배너가 사라진 다음 행동합니다. 기존 경계 상태는 유지됩니다. 이미 시작한 카메라 전환은 잠시 멈췄다가 배너 종료 후 이어집니다. 배너 중 눌렀던 클릭·ESC·회전 키를 예약 실행하지 않습니다. 배너가 끝난 뒤에도 계속 누르고 있는 WASD 키는 평소처럼 동작합니다.

## 설정

`BattleSceneController`가 있는 오브젝트의 **TurnBannerPresenter**에서 이미지와 진입 시간·중앙 대기 시간·퇴장 시간을 조절할 수 있습니다. 저장 씬에는 실행 시 자동으로 추가·연결합니다. 설정을 영구적으로 저장하려면 Edit Mode에서 같은 오브젝트에 컴포넌트를 미리 추가하고 값을 설정하세요. 원래 저장 씬은 자동 수정하지 않습니다.

기본 이미지 위치:

```text
Assets/_Game/Art/UI/Resources/TurnBanners/EnemyTurn.png
Assets/_Game/Art/UI/Resources/TurnBanners/YourTurn.png
```

사용자가 제공한 PNG를 그대로 복사했습니다. 비정방형 크기를 강제로 2의 거듭제곱으로 늘리지 않고, 투명도·Clamp·밉맵 없음·압축 없음으로 UI 가장자리를 유지합니다. 원본 OneDrive 파일과 앞서 만든 중앙 정렬 사본은 변경하지 않습니다.

배너 표시기를 비활성화하거나 제거하면 잠금을 해제합니다. 전투가 종료되면 배너도 즉시 사라집니다. 같은 턴에서 다시 초기화하거나 켜도 이미 표시한 배너를 중복 재생하지 않습니다. 이미지가 없으면 보이지 않는 조작 잠금을 만들지 않습니다.

턴 배너 잠금은 공격 결과 팝업 대기와 별개입니다. **공격 결과 팝업 동안의 카메라 조작은 기존처럼 허용**합니다. 카메라 없는 순수 전투 환경에는 자동 배너를 만들지 않습니다.

## 검증

2026-11-09: 복제본에서 전체 EditMode **942/942**, 그래픽 PlayMode **446/446** 통과. 마지막 정보창 스크롤 입력 차단 보완 후 관련 통합 테스트 **45/45**를 다시 통과했습니다. 기존 씬·데이터·설정의 해시와 제공 PNG 원본 일치를 확인했습니다.

### 카메라 밖 여백의 잔상 방지

전투 카메라가 왼쪽 정보창을 제외한 부분 화면만 그리므로, 화면 전체를 지나가는 배너의 픽셀이 여백에 남을 수 있었습니다. BattleViewportBackground가 카메라 밖 여백만 매 프레임 검정으로 다시 그립니다. 정보창과 배너 뒤에 그리며 카메라의 화면 분할 비율과 설정은 변경하지 않습니다.

잔상 수정 검증: 두 저장 씬의 실제 화면 캡처에서 여백에 남은 픽셀을 재현한 뒤, 배너 표시와 제거 후 검정 여백 복원을 확인했습니다. 관련 그래픽 PlayMode 테스트 **25/25** 통과(2026-11-09).
