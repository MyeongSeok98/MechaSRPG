# 무기 만들기와 시작 장착

## 무기가 지정된 소대 테스트 씬

`Assets/_Game/Scenes/SqurdWeaponTest.unity`를 열고 Play하면 됩니다. 아군3기·적3기의 소대 테스트 씬이며, 기체별 장착은 Unit Weapon Loadout에서 확인합니다. 샘플 StandardRifle/StandardBlade와 직접 지정한 무기를 사용할 수 있습니다. `1V1Test`도 무기 데이터로 이전했습니다. 기존 고정 피해는 `Defaults` 폴더의 무기로 보존하며, 이전 `BattleTest`와 `SqurdBattleTest`는 정리했습니다.

기체 루트의 Unit Weapon Loadout에서 참조를 확인하거나, 전투에서 Attack → 손 위치와 무기 이름 선택 → 발견한 적 선택으로 무기 이름과 피해 범위를 확인하세요. 기본 샘플 StandardRifle은 피해4~6, StandardBlade는 피해7~9이며 둘 다AP3입니다. 직접 만든 무기는 지정한 데이터를 따릅니다. 원본과 같은 시작 거리·시야이므로 적을 조준하려면 탐지와 사거리 조건을 충족해야 합니다. 기체 더블클릭으로 카메라를 해당 기체에 맞출 수 있습니다.

## 새 무기 생성

Project 창에서 `Assets/_Game/Data/Weapons` 아래 폴더를 선택하고 **우클릭 → Create → MechaXCOM → Weapon Data**를 사용합니다. 기존 무기를 선택해 Duplicate(Ctrl+D)하면 변형 무기를 만들 수 있습니다. 같은 에셋을 여러 기체가 공유하면 수치 변경도 함께 반영되므로, 한 기체만 다르게 하려면 복제본을 지정하세요.

샘플은 `Ranged/StandardRifle.asset`, `Melee/StandardBlade.asset`입니다. 각각 피해4~6/명중80/사거리7/AP3, 피해7~9/명중95/사거리2/AP3을 사용합니다. 검증용 초기값이며 Inspector에서 변경할 수 있습니다.

## 데이터 설정

- 공격 종류: Ranged(원거리), Melee(근접).
- 원거리 분류: Beam(빔), Ballistic(실탄), Explosive(폭발물).
- 근접 분류: Edged(날붙이), Blunt(둔기).
- 최소/최대 피해: 양 끝 포함 정수. 같은 값을 넣으면 고정 피해입니다. 실제 피해는 명중할 때 한 번 추첨하며 남은 부위 HP를 초과해 감소시키지 않습니다.
- 기본 명중률, 사거리(맨해튼 거리), 공격 AP 비용을 설정합니다.
- 중량(t)은 이번에는 저장만 합니다. 장착 제한·이동 범위·이동 애니메이션 속도에 영향을 주지 않습니다.
- 파지 조건: OneHandOnly(한손 전용), TwoHandsRequired(양손 필수), Either(겸용).
- 양손 명중 배율: 겸용 무기를 실제 양손으로 사용하는 경우에만 적용합니다. 양손 필수 무기는 기본 명중률을 사용합니다.

분류만으로 관통·절단·폭발 등의 효과가 생기지는 않습니다. 현재 폭발물도 단일 기체/부위 공격입니다.

## 거리별 명중률

원거리 무기의 거리별 명중률 목록에서 `Max Distance`는 구간의 마지막 칸, `Multiplier`는 명중 배율입니다.

| Max Distance | Multiplier | 적용 거리 |
|---|---|---|
| 2 | 0.9 | 1~2칸 |
| 5 | 1.0 | 3~5칸 |
| 7 | 0.8 | 6~7칸 |

상한은 오름차순이며 중복 없이 사거리 안에 있어야 합니다. 자동 정렬하지 않으므로 오류 메시지를 보고 수정하세요. 목록이 비어 있거나 마지막 상한 이후 남는 사거리는 ×1.0입니다. 사거리 밖은 공격할 수 없으며 근접무기는 거리 목록을 사용하지 않습니다. 거리별 피해 변화는 없습니다.

명중률은 기본값에 파지·거리 배율을 먼저 곱하고 기동 회피를 뺀 뒤, 기존 머리 손상·부위 조준·엄폐 배율을 적용합니다. 마지막에0~100%로 제한하고 반올림합니다. 근접의 엄폐/부위 조준 무시 규칙은 유지됩니다.

## 기체에 장착

1. 플레이어 또는 적 기체의 BattleUnit/UnitCombat이 있는 루트 오브젝트를 선택합니다.
2. **Add Component → Unit Weapon Loadout**을 추가합니다.
3. 왼손 무기와 오른손 무기에 에셋을 드래그하고 파지 방식을 선택합니다.
4. Inspector의 손 점유 상태와 오류를 확인합니다.

한손 무기 두 자루는 양쪽에 각각 지정합니다. 같은 에셋을 양쪽에 넣으면 동일 모델의 서로 다른 두 자루입니다. 양손 무기는 한쪽에만 지정해 양손 파지를 선택하고 반대 손 참조는 비웁니다. 겸용 무기도 같은 방식으로 양손 파지를 설정할 수 있습니다.

손 점유 충돌, 무기 조건과 다른 파지, 잘못된 데이터는 전체 장착 오류이며 공격할 수 없습니다. 자동 해제·수납은 하지 않습니다. 컴포넌트를 비활성화해도 예전 공격으로 되돌아가지 않습니다.

**Loadout이 없거나 장착한 무기가 없으면 비무장**입니다. UnitCombat에는 피해·사거리 등의 수치가 없으며 WeaponData를 읽습니다. 새 프리팹 인스턴스에는 Loadout과 무기를 직접 지정하세요.

## 전투에서 사용

기체 선택 → Attack을 누르면 장착 무기를 바로 표시합니다. 한손 무기는 Right/Left와 무기 이름, 양손 파지는 Both hands와 무기 이름으로 한 번만 표시하며 빈손은 생략합니다. 무기가 하나여도 직접 선택한 뒤 조준합니다. AP가 부족한 무기는 목록에 표시하되 선택할 수 없습니다. 이미 손에 든 두 무기 중 공격 수단을 고르는 것이므로 추가 교체 AP는 없습니다.

적 선택 → 원거리 부위 조준 → 명중률·무기 이름·피해 범위·AP 확인 → Fire 순서입니다. 두 Fire 버튼은 같은 선택 무기를 사용합니다. 근접은 몸통을 공격합니다. 한 번에 무기 하나로 공격하며 동시 사격은 하지 않습니다. ESC는 기체 선택까지 해제합니다.

AI는 사용할 수 있는 근접 공격을 우선 확인하고, 같은 종류는 오른손부터 검사해 실행 가능한 무기를 고릅니다. 발견된 적 중 기존 가까운 대상 우선 규칙을 유지하며 이동 시 선택 무기의 사거리와 AP를 사용합니다. 근접 전용 기체는 근접 도달 가능한 위치를 찾고, 비무장/잘못된 장착은 AP 소비 없이 대기합니다. 시야를 잃으면 기존처럼 추적을 취소합니다.

## 현재 하지 않는 것

무기 데이터는 실제 모델·손잡이·총구 위치를 자동 변경하지 않습니다. 전투 중 무기 교체·수납·파지 전환, 양손 모델 자세, 방패, 탄약, 중량 제한, 범위 폭발·곡사·좌표 조준, 팔 파괴에 따른 사용 제한은 이번 구현에 포함하지 않습니다.
