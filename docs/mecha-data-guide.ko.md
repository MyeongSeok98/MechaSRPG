# 기체 기본 스펙 데이터

`Assets/_Game/Data/Mecha/`에 기종별 MechaData 에셋을 저장합니다.

## 생성과 편집

1. Project 창에서 폴더를 선택합니다.
2. 우클릭 → Create → MechaXCOM → Mecha Data로 생성합니다.
3. Inspector에서 한글로 표시되는 기본 스펙을 입력합니다.

`SampleMecha.asset`을 복제(Ctrl+D)해서 시작해도 됩니다. 복제하면 기체 ID도 복사되므로 새 기종에는 ID를 직접 바꾸세요. 현재 중복 ID를 프로젝트 전체에서 검사하는 기능은 없습니다.

## 항목

| 항목 | 기준 |
|---|---|
| 기체 ID | 기종을 구분하는 고유 문자열. 비워둘 수 없습니다. |
| 기체 이름 | 표시용 이름. 비어 있으면 에셋 이름을 사용합니다. |
| 설명 | 자유롭게 작성하는 여러 줄 설명입니다. |
| 모델 프리팹 | Visual 아래 표시할 외형. 생략하면 기존 외형을 유지합니다. |
| 기본 AP | 1 이상의 정수. 초기값 5. |
| AP당 이동거리 | 0보다 큰 칸/AP 값. 초기값 1. 0.5, 1, 2, 3 등 소수도 저장할 수 있습니다. |
| 기본 탐지 거리 | 0 이상의 정수 칸 수. 초기값 10. 0은 탐지 반경 0입니다. |
| 부위별 최대 HP | 몸통·콕피트·머리·양팔·양다리의 최대 내구도. 각각 1 이상. |
| 기체 자체 중량 | 톤(t), 0 이상. |
| 장착 중량 한도 | 톤(t), 0 이상. 기체 자체 중량과 별도로 입력합니다. |
| 실탄 받는 피해 (%) | 50~150. 100은 보정 없음, 낮을수록 실탄에 강함. |
| 빔 받는 피해 (%) | 50~150. 100은 보정 없음, 낮을수록 빔에 강함. |

샘플 최대 HP는 몸통20, 콕피트6, 머리6, 양팔 각8, 양다리 각10입니다. 샘플 중량과 한도는 미설정 참고값인 0이며, 실기체 스펙에 맞게 직접 입력하세요.

## 현재 적용 범위

현재 **부위별 최대 HP·기본 AP·명중력·회피력·기본 탐지 거리·모델을 전투에 연결**했습니다. 유닛의 **BattleUnit → 기체 데이터**에 지정한 MechaData를 사용합니다. 샘플 모델은 `Assets/_Game/Prefabs/Mecha/Samples/MechaReferenceWithRifle.prefab`입니다.

기종을 바꾸려면 해당 유닛의 BattleUnit에서 기체 데이터를 다른 MechaData로 지정하고 Play를 다시 시작하세요. BattleUnit은 초기화 시 최대 HP를 UnitHealth에, 기본 AP를 UnitActionPoints에, 탐지 거리를 UnitVision에, 모델을 UnitMechaVisual에 전달합니다. 이 컴포넌트들은 MechaData를 직접 참조하지 않습니다.

HP·AP 컴포넌트는 전투에 적용된 최대값과 현재 상태를 유닛별로 보관합니다. 턴 시작 시 AP는 적용된 최대 AP까지 회복되며 HP는 자동 회복하지 않습니다. 공유 데이터를 수정하거나 초기화를 다시 호출해도 이미 진행 중인 유닛의 HP·AP를 재설정하지 않습니다. 같은 기종이어도 피해·AP 소비는 서로 독립적입니다.

기체 데이터가 연결되면 UnitHealth와 UnitActionPoints Inspector는 데이터 출처와 최대값을 읽기 전용으로 표시합니다. UnitHealth의 Critical 완전파괴 확률은 계속 별도로 조정할 수 있습니다. 데이터가 없는 기존 테스트·유닛은 기존 컴포넌트 설정을 사용합니다. 잘못된 기체 데이터는 초기화를 거부하며 그리드에 배치하지 않습니다.

다른 외형을 사용하려면 MechaData의 모델 프리팹을 바꾸고 Play를 다시 시작하세요. 편집 화면의 기존 외형은 그대로 보일 수 있으나, 전투 시작 시 Visual 아래 관리하는 모델을 교체합니다. 같은 기종의 모델 프리팹 내부를 편집하면 연결된 외형에도 반영됩니다. 무기 데이터와 무기 외형을 자동 동기화하는 기능은 아직 없습니다.

기존 Visual의 위치·크기·방향을 유지하며, 새 Visual이 필요하면 기체 높이만큼 아래에 발밑 기준점을 만듭니다. 이동·선택 Collider와 진영·시작 위치는 유닛 루트에서 관리합니다. 리깅이 없어도 전체 모델 이동·회전이 가능합니다.

AP당 이동거리는 실제 이동 비용에 적용합니다. 자기 턴 동안 비용을 누적하고 먼저 지불한 이동 여유를 유지하므로 이동·사격·이동을 나눠도 손해를 보지 않습니다. 다리 하나 파괴 시 효율 절반, 둘 다 파괴 시 이동 불가입니다. [이동 AP 가이드](movement-ap.ko.md)를 참고하세요. 장착 중량 한도는0이면 제한 미설정이며 양수이면 초과 장착·전투 시작을 차단합니다. 중량에 따른 이동력 감소와 내부부품 교체는 적용하지 않습니다.

장착 중량에는 빈 무기 본체, 장전 탄창·팩 1개와 기체별로 선택한 예비 개수, 백팩 자체와 포함 무기가 들어갑니다. 기체 자체 중량은 별도입니다. WeaponData에서 본체/탄창 중량을 각각 입력하고 UnitWeaponLoadout에서 예비 개수를 선택합니다. 백팩의 예비는 0개이며 재장전할 수 없습니다. [탄약 설정 가이드](weapon-ammo.ko.md)를 참고하세요.

장갑 타입 선택은 두 받는 피해율로 대체했습니다. 기존 대빔/대실탄 에셋은 기존 80%/110% 효과로 읽고, 슬라이더에서 명시한 값이 우선합니다. 추가부품의 미래 보정은 기체별 최종 배율 함수에 연결할 수 있으며 부품 기능 자체는 아직 없습니다. [피해율 가이드](damage-taken-percent.ko.md)를 참고하세요.

현재 HP·AP·위치·상태·장착 무기는 공유 에셋에 저장하지 않습니다.

## 기본 탐지 거리 조절

1. 유닛의 BattleUnit에 연결된 MechaData 에셋을 선택합니다.
2. Inspector의 **기본 탐지 거리 (칸)**를 변경합니다.
3. Play를 다시 시작하면 해당 기체의 UnitVision과 기존 적 발견·전장의 안개·AI 탐지에 반영됩니다.

현재 최종 탐지 거리는 이 기본값과 같습니다. 원형 범위의 경계도 포함하지만 건물 등의 시야 차단은 그대로 적용합니다. 다른 아군과의 공유 시야 규칙도 유지합니다. 추가부품 보너스와 머리·센서 파괴에 따른 탐지 감소는 아직 없습니다.

MechaData가 있으면 유닛의 기존 UnitVision Inspector 값보다 기체 데이터가 우선합니다. 기체 데이터가 없는 유닛은 기존 UnitVision 설정을 유지하고, UnitVision도 없으면 기본10칸을 사용합니다. 기존 기체 에셋에 새 필드가 없어도 기본10칸으로 읽습니다.

값은 전투 시작 시 유닛에 복사합니다. 실행 중 공유 MechaData를 바꾸거나 턴을 넘겨도 다시 덮어쓰지 않으며, 같은 그리드로 Initialize를 재호출해도 유닛별 적용 값을 초기화하지 않습니다. UnitVision.Configure로 유닛의 값을 변경하면 기존 변경 알림으로 시야를 갱신하며 공유 에셋이나 다른 유닛의 값은 바뀌지 않습니다.
