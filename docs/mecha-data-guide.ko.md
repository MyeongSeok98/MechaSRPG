# 기체 기본 스펙 데이터

`Assets/_Game/Data/Mecha/`에 기종별 MechaData 에셋을 저장합니다.

## 생성과 편집

1. Project 창에서 폴더를 선택합니다.
2. 우클릭 → Create → MechaXCOM → Mecha Data로 생성합니다.
3. Inspector에서 한글로 표시되는 기본 스펙을 입력합니다.

`SampleMecha.asset`을 복제(Ctrl+D)해서 시작해도 됩니다. 복제하면 기체 ID도 복사되므로 새 기종에는 ID를 직접 바꾸세요. 현재 중복 ID를 프로젝트 전체에서 검사하는 기능은 없습니다.

## 항목

| 항목 | 기준 |
|---|---|
| 기체 ID | 기종을 구분하는 고유 문자열. 비워둘 수 없습니다. |
| 기체 이름 | 표시용 이름. 비어 있으면 에셋 이름을 사용합니다. |
| 설명 | 자유롭게 작성하는 여러 줄 설명입니다. |
| 모델 프리팹 | Visual 아래 표시할 외형. 생략하면 기존 외형을 유지합니다. |
| 기본 AP | 1 이상의 정수. 초기값 5. |
| AP당 이동거리 | 0보다 큰 칸/AP 값. 초기값 1. 0.5, 1, 2, 3 등 소수도 저장할 수 있습니다. |
| 부위별 최대 HP | 몸통·콕피트·머리·양팔·양다리의 최대 내구도. 각각 1 이상. |
| 기체 자체 중량 | 톤(t), 0 이상. |
| 장착 중량 한도 | 톤(t), 0 이상. 기체 자체 중량과 별도로 입력합니다. |

샘플 최대 HP는 몸통20, 콕피트6, 머리6, 양팔 각8, 양다리 각10입니다. 샘플 중량과 한도는 미설정 참고값인 0이며, 실기체 스펙에 맞게 직접 입력하세요.

## 현재 적용 범위

현재 **부위별 최대 HP·기본 AP·모델을 전투에 연결**했습니다. 아군 BattleUnit과 적 DummyEnemy 프리팹의 **BattleUnit → 기체 데이터**가 SampleMecha를 참조합니다. 두 샘플씬에 공통으로 적용됩니다. 모델은 `Assets/_Game/Prefabs/Mecha/Samples/MechaReferenceWithRifle.prefab`입니다.

기종을 바꾸려면 해당 유닛의 BattleUnit에서 기체 데이터를 다른 MechaData로 지정하고 Play를 다시 시작하세요. BattleUnit은 초기화 시 최대 HP를 UnitHealth에, 기본 AP를 UnitActionPoints에, 모델을 UnitMechaVisual에 전달합니다. 이 컴포넌트들은 MechaData를 직접 참조하지 않습니다.

HP·AP 컴포넌트는 전투에 적용된 최대값과 현재 상태를 유닛별로 보관합니다. 턴 시작 시 AP는 적용된 최대 AP까지 회복되며 HP는 자동 회복하지 않습니다. 공유 데이터를 수정하거나 초기화를 다시 호출해도 이미 진행 중인 유닛의 HP·AP를 재설정하지 않습니다. 같은 기종이어도 피해·AP 소비는 서로 독립적입니다.

기체 데이터가 연결되면 UnitHealth와 UnitActionPoints Inspector는 데이터 출처와 최대값을 읽기 전용으로 표시합니다. UnitHealth의 Critical 완전파괴 확률은 계속 별도로 조정할 수 있습니다. 데이터가 없는 기존 테스트·유닛은 기존 컴포넌트 설정을 사용합니다. 잘못된 기체 데이터는 초기화를 거부하며 그리드에 배치하지 않습니다.

다른 외형을 사용하려면 MechaData의 모델 프리팹을 바꾸고 Play를 다시 시작하세요. 편집 화면의 기존 외형은 그대로 보일 수 있으나, 전투 시작 시 Visual 아래 관리하는 모델을 교체합니다. 같은 기종의 모델 프리팹 내부를 편집하면 연결된 외형에도 반영됩니다. 무기 데이터와 무기 외형을 자동 동기화하는 기능은 아직 없습니다.

기존 Visual의 위치·크기·방향을 유지하며, 새 Visual이 필요하면 기체 높이만큼 아래에 발밑 기준점을 만듭니다. 이동·선택 Collider와 진영·시작 위치는 유닛 루트에서 관리합니다. 리깅이 없어도 전체 모델 이동·회전이 가능합니다.

AP당 이동거리·중량 제한은 아직 데이터만 저장합니다. 기존 이동 범위와 칸당 AP 1 규칙은 유지하며, AP당 이동 비용 계산 전환·중량 초과 페널티·내부부품 교체는 별도 작업입니다.

현재 HP·AP·위치·상태·장착 무기는 공유 에셋에 저장하지 않습니다.
