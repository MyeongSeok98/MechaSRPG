# 무기 특성

WeaponData 에셋 Inspector의 **무기 특성** 목록에서 필요한 항목을 추가한다. 현재 지원하는 특성은 **건물 너머 곡사 가능** 하나다. 기본 목록은 비어 있으며 기존 무기에도 자동으로 추가하지 않는다.

## 건물 너머 곡사 가능

이 특성은 원거리 → 폭발물 → 곡사 무기에만 효과가 있다.

| 판정 | 특성 없음 | 특성 있음 |
|---|---|---|
| 발사점과 착탄점 사이의 큰 건물 | 발사 차단 | 넘어갈 수 있음 |
| 큰 건물 칸 자체 조준 | 불가 | 가능 |
| 일반 Half/Full 엄폐물·골짜기 | 발사 차단 안 함 | 동일 |
| 맵 경계·맨해튼 사거리 | 제한 유지 | 제한 유지 |
| 착탄점에서 대상까지 퍼지는 폭발 | 건물이 차단 | 동일 |
| 직사 공격 | 기존 차단 유지 | 기존 차단 유지 |

건물은 GridObstacle의 Blocks Shots가 켜진 그리드 칸으로 판정한다. 실제 건물 높이나 포물선 궤적을 계산하지 않는다. 그리드 선분이 정확히 모서리를 지날 때 옆 건물에 닿는 경우도 차단한다. 다른 기체는 발사 경로를 막지 않는다.

범위 표시·좌표 선택·Fire 확정·적 AI는 같은 착탄점 검증을 사용한다. 준비 중 경로가 막히면 Fire가 거부되며 AP·탄약을 쓰지 않는다. 특성이 없는 무기도 건물을 통과하지 않는 사거리 내 시야 밖·미탐험 칸을 조준할 수 있다.

## 코드와 확장

- `Scripts/Combat/WeaponTrait.cs`: 특성 enum. 직렬화 번호를 바꾸지 않고 새 항목에 고유 번호를 추가한다.
- `Scripts/Combat/WeaponData.cs`: 특성 목록과 `HasTrait(WeaponTrait)`. null은 빈 목록으로 취급하고 중복/알 수 없는 항목은 잘못된 설정으로 표시한다.
- `Scripts/Combat/CombatSystem.Indirect.cs`: 특성에 따른 발사 경로 검사. 범위 표시와 실제 공격에서 함께 사용한다.
- `Scripts/Grid/GridManager.cs`: 건물 발사 경로와 폭발 경로를 각각 제공한다.
- `Scripts/AI/EnemyAIController.cs`, `Scripts/Grid/Pathfinder.cs`: 곡사무기로 이동 후 발사할 위치를 찾을 때도 같은 발사 경로 검사를 사용한다.

경로는 Assets/_Game 기준이다. 새 특성은 enum에 등록하는 것만으로 효과가 생기지 않는다. 실제 해당 판정에 HasTrait 검사를 연결하고 검증해야 한다. 피해량·사거리·폭발 반경 같은 수치는 기존 무기 필드에서 관리한다. 별도 특성 에셋이나 파일럿 패시브 시스템은 추가하지 않았다.

엄폐물 체력·파괴는 아직 구현하지 않았다. 이 기능은 곡사 발사 경로만 변경한다.
