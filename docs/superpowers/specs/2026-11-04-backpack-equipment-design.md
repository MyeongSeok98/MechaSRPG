# 일체형 백팩 무장 설계

## 확정된 게임 규칙

사용자와 대화에서 확정한 설계를 기록한다. 이 문서를 작성하는 작업은 설계·구현계획 작성이며 제품 코드 구현 완료를 의미하지 않는다.

1. 백팩과 포함 무장은 하나의 장비다. 무장 백팩에는 무기 하나만 포함된다.
2. 무장 없는 일반 백팩과 백팩 미장착을 허용한다.
3. 백팩을 교체하면 포함 무장도 함께 교체된다. 유닛에서 포함 무기만 따로 바꾸지 않는다.
4. 손을 점유하지 않으며 한손/양손 무장과 함께 사용할 수 있다.
5. 탄약을 사용하는 백팩 무장은 전투 시작 시 장전된 탄약만 사용한다. 예비 탄약은 0이고 재장전할 수 없다.
6. Attack 메뉴에 포함 무기 이름을 표시한다. 탄약 소진 시 사격 불가이며 Reload 목록에는 표시하지 않는다.
7. 백팩 장착 중량은 백팩 자체 중량 + 포함 무기 중량이다. 무기를 별도로 한 번 더 합산하지 않는다.
8. BackpackData는 선택적인 WeaponData 하나를 참조한다. 잔탄은 유닛별 런타임 상태로 관리하며 공유 에셋을 수정하지 않는다.

## 기존 구조와 접근 방식

현재 WeaponSlot과 UnitWeaponLoadout/UnitWeaponAmmo는 두 손만 다룬다. UnitCombat은 무기를 손에서 찾고 팔 상태를 검사한다. PlayerInputController와 BattleDebugUI도 두 손을 직접 순회하며, UnitActionUI 무기 선택창은 두 행 높이가 고정되어 있다.

선택한 방식은 기존 UnitWeaponLoadout에 백팩 참조를 추가하고 기존 WeaponSlot 뒤에 Backpack을 추가하는 것이다. 별도 백팩 공격 시스템을 만들면 명중률·부위 피해·장갑·치명타·탄약·AI 경로가 중복된다. 모든 장비를 새 범용 인벤토리로 재작성하는 방식은 현재 범위를 넘는다.

## 구현상 선택과 초기 범위

다음은 규칙을 기존 코드에 연결하기 위한 구현 선택이다.

- 기존 손 슬롯 enum 값 RightHand=0, LeftHand=1 및 직렬화 필드는 유지한다. Backpack=2를 추가한다.
- 백팩 무기도 기존 WeaponData의 공격 타입·AP·사거리·명중률·거리 보정·피해·장탄 수를 사용한다. 파지/양손 보너스는 백팩에 적용하지 않는다.
- 팔 파괴는 백팩 무장의 사용을 막지 않는다. 유닛의 Critical/Destroyed/Ejected 및 공통 행동 조건은 그대로 적용한다. 백팩 자체 부위 HP는 이번에 추가하지 않는다.
- 원거리 백팩은 기존 경계사격 규칙을 재사용한다. 별도 경계 금지 규칙은 추가하지 않는다. 마지막 탄약 소진 시 경계가 해제되고 이동 처리가 정상 해제되어야 한다.
- 같은 WeaponData를 손과 백팩 또는 여러 유닛에서 공유해도 잔탄은 각각 독립적이다. 재장전 금지는 장착 위치의 규칙이므로 WeaponData의 손 무기 재장전 능력을 바꾸지 않는다.
- 백팩 교체는 우선 전투 시작 전 Inspector 장착 설정에서 수행한다. 전투 중 교체/재장전으로 잔탄을 복구하는 기능은 제공하지 않는다. 초기화 반복·턴 변경·컴포넌트 재활성화로 탄약을 채우지 않는다.
- 총 장착 중량을 계산·표시한다. 출격/편성 화면, 과적 출격 제한, 예비 탄약 무게, 이동력 변경은 별도 작업이다. 기존 중량 한도 0인 에셋을 임의로 변경하거나 현재 전투를 막지 않는다.
- BackpackData에 선택적 모델 프리팹을 저장할 수 있으나 실제 백팩 모델/장착점/애니메이션은 이번 첫 구현에 포함하지 않는다. 기존 메카·라이플 외형과 위치를 유지한다.
- 기존 씬에 백팩을 자동 장착하지 않는다. 신규 샘플 백팩 에셋으로 Inspector에서 연결해 검증할 수 있게 한다.

## 책임

| 구성 | 책임 |
|---|---|
| BackpackData | ID/이름/설명, 백팩 자체 중량, 포함 WeaponData, 선택적 모델 |
| UnitWeaponLoadout | 장착한 백팩, 슬롯별 무기 조회, 장비 유효성 및 중량 합산 |
| UnitWeaponAmmo | 백팩 잔탄과 손 무기 잔탄의 독립 상태, 백팩 재장전 거부 |
| UnitCombat / CombatSystem | 공통 공격 스펙 수집, 미리보기/실행/AP/피해 계산 |
| Input / Presentation | 세 슬롯 목록, 실제 선택/표시, 재장전 목록 제외 |
| AI / Overwatch | 기존 공통 공격 경로 이용, 사용 불가/탄약 소진 처리 |
