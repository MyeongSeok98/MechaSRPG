# 직사 폭발무기의 추가 부위 피해

사용자가 확정한 설계: 선택한 적 한 기체의 조준 부위에 직격 피해를 주고, 같은 기체의 다른 정상 부위 중 무기에서 정한 수만큼 무작위로 골라 부가 피해를 준다. 직격 부위에 관계없이 무기별 공통 최소·최대 비율을 사용한다. 직격 부위·콕피트·파괴된 부위를 제외하고 중복 없이 선택하며 후보 부족 시 가능한 부위만 선택한다. 각 부가 부위의 비율은 독립적으로 추첨한다. 빗나가거나 공격이 거부되면 부가 피해가 없다. 모든 HP 변경 후 기체 상태를 한 번 판정한다.

직사 폭발물은 현재 Ranged/Explosive 분류의 적 지정 공격으로 한정한다. 곡사·좌표 선택·범위 피해·다른 유닛 피격은 구현하지 않는다. 부가 피해의 기준은 기존 치명타·장갑·파일럿 보정을 적용한 직격 피해이며 대상 HP에 의해 잘리기 전의 값이다. 보정을 다시 곱하거나 부가 명중/치명타 판정을 추가하지 않는다. 기존과 같은 양수 정수 반올림 규칙을 사용한다.

데이터: 추가 부위 수0~6, 최소/최대 배율0~1, 최소≤최대, 유한값. 호환성을 위해 부위 수 기본0으로 비활성화한다. 비율 기본5~15%는 편집 시작용 예시이며 확정 밸런스가 아니다. 기존 기체·무기 에셋은 자동 수정하지 않는다. 근접·빔·실탄에는 이 설정을 적용하지 않는다.

책임: WeaponData 설정, CombatSystem 추첨/총 피해 생성, UnitHealth 배치 HP 적용 및 최종 상태·이벤트, AttackPreview/AttackResult와 기존 UI의 추가 피해 안내. 일반 공격·AI·백팩·경계는 공통 실행 경로를 사용한다. AP·탄약은 한 발 기준으로 한 번만 소모한다. 미리보기는 무작위 값을 소비하거나 특정 추가 부위를 확정하지 않는다.

여러 번 ApplyDamage를 호출하는 대안은 중간 파괴로 후속 피해가 누락되거나 Critical 판정을 반복할 수 있어 제외한다. 기존 단일 부위 API를 유지하면서 배치 API를 추가하는 방식을 선택한다. 한 발의 최종 HP/상태가 확정된 다음 기존 순서(StateChanged 후 PartDestroyed)로 이벤트를 알린다.
