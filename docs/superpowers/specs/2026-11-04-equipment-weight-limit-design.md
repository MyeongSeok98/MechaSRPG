# 장착 중량 한도

사용자 승인: 한도 초과 장착 및 출격을 차단한다. 한도0은 제한 미설정이며 양수일 때만 적용한다.

이동력 감소와 무제한 초과 장착 방식 대신, 현재 총 장착 중량을 그대로 사용해 제한한다. 손 무기+백팩 자체+포함 무장만 합산하며 소체와 예비 탄약 무게는 제외한다. 한도와 정확히 같은 중량은 허용한다.

UnitWeaponLoadout이 후보 장착 중량을 검증한다. 초과 변경은 기존 장비와 이벤트를 보존하고 거부한다. Inspector 다중 선택에도 동일 검증을 적용한다. MechaData 변경이나 공유 장비 에셋 수정으로 기존 설정이 초과될 수 있으므로 경고를 표시하고, BattleSceneController가 그리드 생성·기체 초기화 전에 전투 전체를 차단한다. BattleUnit 직접 초기화도 동일 검사한다. MechaData가 없는 레거시 유닛은 제한을 적용하지 않는다.

기존 씬·에셋·카메라·속도·엄폐 설정은 수정하지 않는다. 새 출격 화면, 자동 무장 해제, 중량에 따른 이동 변화는 만들지 않는다.

복구·정밀도: 기존 초과 상태에서는 장비를 빼는 변경만 단계적으로 허용하고, 새 장비로 교체하는 변경과 출격은 차단한다. 중량 합산은 Unity float 표현 오차만 근사 동등 비교로 허용하며 실제 초과 중량은 차단한다.
