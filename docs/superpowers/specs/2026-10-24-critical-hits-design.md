# 기량 차이에 따른 치명타

사용자가 승인한 치명타 규칙을 기존 공통 공격 처리에 적용한다. 기체의 Critical 상태/완전파괴 판정과 구분한다.

- 공격자/대상 파일럿 기량을 각각 0~50으로 제한해 차이를 계산한다.
- 차이 <= -20: 0%; -20 < 차이 < 0: 5 + 차이 * 0.25%; 차이 >= 0: 5 + 차이 * 0.9%. 최대 50%.
- 명중한 공격만 독립적인 치명타 추첨을 한다. 소수 확률을 보존하며 미리보기는 난수를 소비하지 않는다.
- 기본 피해 배율은 1.25. 모든 보정 이후 한 번 반올림(0.5 올림)한다. 기존 HP 차감과 파괴 규칙을 그대로 호출한다.
- 일반 원거리/근접, 적 AI, 경계사격에 공통 적용한다.
- BattleUnit에 CharacterData 연결을 추가하고 초기화 때 기량을 복사한다. 파일럿 미지정은 기량 0, 동률 기본 5%로 취급한다(구현 판단).
- 사격/근접/회피 능력치, 성장, 아이템/스킬 시스템은 추가하지 않는다. 이번에는 치명타 배율의 기본값만 제공한다.
- UI에 치명타 확률/배율과 실제 발생 여부를 표시한다. 기존 씬의 파일럿 배정은 변경하지 않는다.

## Approaches
공격 유형마다 계산을 복제하면 AI/경계사격과 불일치할 수 있다. 공통 CombatMath와 CombatSystem.ExecuteAttack에 계산/실행을 모으는 기존 구조를 유지한다.

## 검증
경계값, 소수 확률, 성공/실패/명중 실패, 피해 반올림, 미리보기 무작위성 배제, 기량 복사, 경계사격을 검증한다. 기존 테스트는 독립 치명타 난수를 고정한다. 테스트는 기존 격리 Unity 프로젝트에서 실행하고 사용자 데이터/씬/카메라/이동 속도를 보존한다. Git은 사용하지 않는다.
