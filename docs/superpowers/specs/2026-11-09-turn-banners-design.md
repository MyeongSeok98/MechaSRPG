# 턴 시작 배너

플레이어 진영 시작에는 사용자가 제공한 YourTurn.png, 적 진영 시작에는 EnemyTurn.png를 화면 중앙에 표시한다. 처음 전투 시작의 플레이어 턴도 포함한다. 오른쪽 밖에서 0.15초 진입 → 중앙 0.4초 정지 → 왼쪽 밖으로 0.15초 퇴장하며 페이드아웃한다. 투명 이미지의 비율을 유지하고 화면 너비의 약 90%로 표시한다. 시간은 unscaled time을 사용한다.

배너 동안 선택·ESC·이동·공격·재장전·경계·탈출·턴 종료·카메라 WASD/Q/E/휠/더블클릭 초점 조작을 차단한다. 이미 진행 중인 카메라 전환도 배너 동안 멈추고 종료 후 재개한다. 적 AI는 EnemyTurn 배너가 끝난 뒤 시작한다. 입력은 버퍼링하지 않는다. 기존 공격 결과 팝업은 카메라를 막지 않으며 그 동작은 그대로 둔다.

TurnManager의 진영 시작 이벤트를 독립 TurnBannerPresenter가 받는다. 별도의 턴 표시 소유권/기한을 관리해 기존 공격 결과 대기와 섞지 않는다. BattleSceneController가 카메라가 있는 실제 전투 UI에 런타임 연결하고 초기 턴을 즉시 표시한다. 순수 전투 로직 테스트/카메라 없는 환경에는 UI 대기를 만들지 않는다. 표시기 비활성화/파괴/전투 종료 시 잠금을 해제하고 중복 초기화로 재생하지 않는다. 이미지가 없으면 보이지 않는 잠금을 만들지 않는다.

사용자 지정 원본 PNG를 그대로 Art/UI/Resources/TurnBanners에 복사하며 이미지 재생성·픽셀 편집은 하지 않는다. 화면 렌더에 Resources.Load를 사용하며 Inspector에서 시간/이미지를 바꿀 수 있다. 기존 중앙 정렬 사본과 원본 파일은 유지한다. 기존 씬·데이터·모델·재질·속도·카메라 튜닝·그림자·엄폐 보정은 바꾸지 않는다. 이번 요청에 Git 작업은 없다.
