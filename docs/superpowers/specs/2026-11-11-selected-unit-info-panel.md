# 선택 기체 정보 패널

사용자 예시의 정보 배치를 실제 uGUI 프리팹으로 구현한다. 기존 올리브색 반투명 9-slice 프레임을 배경으로 사용한다. 이름(기체/파일럿),4:5 초상화,현재/최대 AP,활성 여부와 현재 행동 상태,UNIT STATUS 목록만 제공한다. 무장 목록과 노란 알림은 없다.

부위 목록은 IUnitStatusSource의 표시용 데이터로 받는다. UnitHealth는 기존7개 부위, CoverDurability는 단일 Body를 제공한다. 부위 체력 로직/전투불능 규칙은 변경하지 않는다. 보병/전투기 전투 시스템을 새로 구현하는 범위는 아니다. 각 행은 라벨·HP바·현재/최대 숫자를 보여주고 파괴되면 빈 붉은 바로 구분한다. 행 수에 따라 높이가 달라지고, 긴 목록은 상태 영역만 세로 스크롤한다.

기존 선택과 시야 규칙을 재사용한다. 매 프레임 읽기 전용으로 AP/HP/상태를 갱신하고 선택 해제·시야 상실·전투불능으로 선택이 제거되면 숨긴다. 적은 정보만 표시한다. 포트레이트는 기존 파일럿 Default/샘플 대체 규칙을 쓴다. 표정 이벤트는 범위 밖이다.

기존4씬에 새 패널 프리팹 참조를 추가한다. 디버그 정보는 F3 전환으로 남겨 두고 새 패널과 겹쳐 그리지 않는다. 임무/현재 턴/End Turn은 작은 우측 상단 컨트롤로 남겨 전투 기능을 보존한다. UI 영역에서 월드 선택/이동이 일어나지 않게 기존 입력 차단과 연결한다. 카메라/전투 수치/장착/기체·파일럿 데이터는 변경하지 않는다.
