# 적별 수동 경계사격 설계

상태: 2026-10-22 사용자가 이 설계대로 구현계획 작성을 요청해 문서 승인 완료. [구현계획](../plans/2026-10-22-interactive-overwatch.md) 승인 완료. 단계1~5 구현·검증·문서 갱신·독립 검토 및 발견 사항 수정 완료. 최종 EditMode467/467·그래픽 PlayMode318/318 통과, 실패·건너뜀0.

## 목적과 확정한 사용자 의도

기존 경계는 처음 반응한 적에게 몸통을 자동 사격한 뒤 종료한다. 이를 **경계 기체마다, 서로 다른 적마다 한 번씩 사격 여부와 조준 부위를 결정하는 방식**으로 변경한다.

사용자가 승인한 흐름:

1. 적이 감시 조건을 만족하는 칸으로 이동하면 이동을 잠시 멈춘다.
2. 플레이어가 해당 적의 부위별 명중률을 확인한다.
3. 조준 부위를 선택해 Fire를 누르거나 Skip으로 넘긴다.
4. 처리 후 적의 이동·행동을 재개한다.
5. 다른 적이 조건을 만족하면 새 기회를 제공한다.
6. 이미 사격했거나 Skip한 적은 같은 경계가 끝날 때까지 다시 묻지 않는다.

기존 진입 비용 AP 2, 사격 추가 AP 없음, 명중률 ×0.75, 다음 자기 진영 턴 시작 시 만료는 유지한다. 이번에는 적 수와 별개인 총 발사 횟수 제한이나 탄약 시스템을 추가하지 않는다.

## 적용 범위와 구현 접근

아군의 경계 선택과 적 AI 이동에 대한 플레이어의 반응 결정을 구현한다. 적 AI가 경계를 선택하는 행동은 추가하지 않는다.

기존 OverwatchSystem의 칸 완료 코루틴을 입력 대기까지 확장하고, 기존 부위 이미지와 명중률·피해 계산을 재사용하는 방식을 채택한다. 별도 전투 시스템이나 범용 반응 이벤트 버스는 만들지 않는다. 일반 공격의 자기 턴·AP·이동 중 금지 조건은 그대로 유지한다.

새 범용 인터럽트 프레임워크는 현재 기능보다 범위가 크고, 기존 일반 공격 모드에 적 턴 권한을 열면 잘못된 일반 공격을 허용할 수 있으므로 채택하지 않는다. 경계 전용 결정 상태를 두고 공통 표시·계산만 재사용한다.

## 감시와 대상별 기회

- 기존 전방 90도, 맨해튼 무기 사거리, 사수 개인의 원형 탐지 거리, 시야·사선 조건을 유지한다.
- 적의 한 칸 이동 완료 후 점유·이동 AP·이동 기록을 갱신하고 다음 칸으로 이동하기 전에 판정한다.
- 처음부터 범위 안에 있던 적도 이동하면 판정한다. 경계 진입·정지·회전·일반 공격만으로는 발동하지 않는다.
- 각 경계 기체는 현재 경계에서 **결정이 끝난 적의 집합**을 보관한다. 기체 이름이나 좌표가 아닌 BattleUnit 인스턴스로 구분한다.
- Fire가 실제로 실행되면 명중·빗나감 모두 그 적의 기회를 사용한다. 사수의 전체 경계는 유지한다.
- Skip도 그 사수와 적 사이의 기회를 사용한다. 적이 여러 칸 이동하거나 범위에서 나갔다 돌아와도 같은 경계에서는 다시 묻지 않는다.
- 창을 열거나 부위를 바꾸는 것만으로 기회를 사용하지 않는다. Fire 시 재검증 실패라면 발사한 것으로 기록하지 않는다.
- 사수마다 기록이 독립적이다. A 사수가 적 X를 Skip해도 B 사수는 X에게 사격할 수 있다.
- 다음 턴 만료·취소 시 대상 기록을 비우며, 다음 경계에서는 같은 적을 다시 대상으로 삼을 수 있다.

## 입력 대기와 부위 조준

대기 창에는 사수·선택 무기·현재 적·조준 부위·부위 HP·최종 명중률·피해 범위와 Fire / Skip을 표시한다. 부위 이미지는 기존 BodyTargetUI의 자산과 클릭 영역을 재사용한다.

- 새로운 사수/적 기회마다 기본 조준은 몸통이다. 이전 적의 콕피트 선택 등을 이어받지 않는다.
- 머리·몸통·콕피트·좌우 팔·좌우 다리를 선택할 수 있다. 기존 부위 선택·피격 규칙을 따른다.
- 명중률은 기존 원거리 식에 선택 부위와 경계 ×0.75를 반영하며, 마지막에 한 번 제한·반올림한다.
- 경계 진입 시 선택한 무기로만 사격한다. 대기 창에서 무기를 바꾸지 않는다.
- Fire는 현재 유효한 요청에만 적용하며 이중 클릭·이전 창의 입력으로 두 번 발사할 수 없다.
- Skip은 명중/피해 난수와 AP를 소비하지 않는다.
- 선택 중에는 다른 기체 선택, 일반 Move / Attack / Eject, 경계 재설정, 턴 종료를 차단한다. 카메라 이동·회전·줌은 계속 허용한다.
- 이 대기 창에서는 ESC나 허공 클릭으로 선택을 풀어 대기가 남는 상황을 만들지 않는다. **Fire 또는 명시적인 Skip**으로 결정한다. 일반 행동의 ESC 동작은 유지한다.
- 창은 일반 공격 패널과 동시에 열리지 않는다. 대기가 끝나면 해당 경계 UI를 닫고, 이후 요청에는 조준 상태를 새로 초기화한다.

## 여러 사수와 이동 재개

하나의 적이 여러 아군 경계에 걸리면 기존 전투 유닛 등록 순서대로 한 사수씩 선택 기회를 준다. 여러 창을 동시에 열거나 플레이어가 다른 표적으로 변경하게 하지 않는다.

```text
적 한 칸 도착
→ 사수 A의 Fire / Skip 대기
→ 결과 적용·다음 사수 조건 재검사
→ 사수 B의 Fire / Skip 대기
→ 모든 유효 사수 처리 완료
→ 적의 이동·행동 가능 상태 재검사
→ 이동 재개 또는 중단
```

- 앞선 사격으로 적이 Destroyed / Ejected / 비활성 상태가 되면 이후 사수의 창을 열지 않는다.
- Critical은 아직 피격 가능하므로 다음 사수에게 선택 기회를 제공할 수 있다. 모든 반응이 끝난 뒤 해당 적의 이동·공격은 중단한다.
- 한쪽 다리가 파괴되면 다음 칸 전에 손상된 이동 범위와 이미 이동한 거리를 재검사한다. 양 다리가 파괴되면 중단한다.
- 현재 AI는 이동 중 매 프레임 행동 가능 여부를 검사한다. 입력 대기 중 앞선 사격으로 Critical이 되어도 AI가 남은 반응을 임의 취소하지 않도록, **진행 중 반응이 끝나는 것을 먼저 기다린 후** 이동 재개 여부를 판단해야 한다.
- 이미 도착한 칸의 이동 AP는 환급하지 않는다. 남은 이동 경로는 유효할 때만 재개한다.
- 한 적을 처리해도 사수 경계는 다음 적을 위해 유지한다. 이동·일반 공격 제한과 긴급탈출 허용은 종전과 같으며, 반응 창이 열린 동안만 탈출 입력도 차단한다.

## 만료·무효화와 정리

다음 자기 진영 턴 시작 시 AP 회복 전에 만료한다. 무기 변경·전투불능·탈출·비활성화·전투 종료에 의한 취소 규칙도 유지한다.

사용자 입력을 기다리는 시간이 생기므로 각 요청에 사수·적·슬롯과 요청 식별자를 묶는다. 미리보기와 Fire / Skip은 현재 요청에만 적용한다.

- 대기 중 사수·무기·적·개인 시야·사선이 무효가 되면 해당 요청을 닫고 재검사한다. 발사하지 않은 사수/적 기회를 임의로 소모하지 않는다.
- 사수만 무효라면 다른 유효 사수를 계속 처리할 수 있다. 이동 대상·서비스·전투 자체가 무효라면 해당 이동 반응 전체를 종료한다.
- 이동 취소, AI/이동/경계 서비스 비활성화, 씬 종료, 전투 종료에서 대기 요청·UI·코루틴 처리 참조·busy 상태를 정리한다.
- UI/입력 담당 컴포넌트가 비활성화되어 결정을 받을 수 없으면 현재 요청을 취소하고 반응 처리를 풀어 준다. 이를 Fire나 Skip으로 기록하지 않는다. UI가 없는 상태에서 플레이어 입력 요청을 만들고 무한 대기하지 않는다.
- 정리된 요청의 늦은 Fire / Skip은 거부한다. UI를 다시 켜도 이전 요청을 복원하거나 발사하지 않는다.

## 검증 범위

EditMode:

- 사수 A의 적 X 처리 기록이 적 Y 또는 사수 B에게 영향을 주지 않음.
- Fire·빗나감·Skip 후 같은 적 재요청 금지, 새 경계에서는 다시 허용.
- AP 2 진입·발사 추가 비용 없음·무기 일반 공격 비용과 독립.
- 선택 부위·엄폐·거리·파지·머리 손상·×0.75의 미리보기와 실제 판정 일치.
- 무효 요청·이전 요청·중복 Fire 거부, 일반 공격 권한 유지.

PlayMode:

- 실제 적 AI 이동이 입력 전까지 같은 칸에서 멈춤. Fire / Skip 후 재개하고 다음 플레이어 턴까지 진행.
- 여러 적에게 각각 한 번 요청, Skip한 적의 다음 칸·재진입에서 재요청 없음.
- 여러 사수의 순차 창, 한 사수 Skip 후 다른 사수 발사, 중간 파괴 시 후속 창 없음, Critical 후 남은 사수 처리.
- 다리·머리 조준 피해가 기존 손상 규칙과 이동 재검사에 반영됨.
- 실제 부위 클릭·명중률·Fire / Skip, 다른 전투 입력 차단·카메라 조작 유지·UI 겹침 없음.
- 전투 종료·기체/이동/AI/입력/UI/서비스 비활성화·무기 변경 도중 대기 정리, 오래된 입력 거부와 busy 해제.
- 저장된 1V1Test / SqurdWeaponTest의 런타임 연결과 원본 파일 보존.
- 기존 경계 테스트의 1회 전체 소모·몸통 자동 사격 기대를 새 규칙으로 수정하고 전체 EditMode / 그래픽 PlayMode 회귀 검증.

## 범위 밖

탄약·총 발사 횟수 제한·반응마다 AP 소비·적 AI 경계 진입·자동 조준 정책·일반 공격 개편·파일럿 능력치/패시브 연결·새 사격 연출은 추가하지 않는다.
