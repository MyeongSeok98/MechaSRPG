# 무기 데이터·시작 장착·공격 연결 설계

## 승인 범위

사용자와 2026-10-14까지 합의한 첫 구현 범위를 반영한다. Unity에서 코드 수정 없이 무기 에셋을 생성·복제하고, 기체의 시작 장착과 파지를 지정하며, 플레이어와 적이 그 수치로 공격한다. 이 문서는 2026-10-13 초안의 근접/원거리 고정 슬롯·고정 피해 설계를 대체한다. 사용자의 구현계획 작성 요청에 따라 최신 범위를 문서화한다.

## 무기 데이터

WeaponData ScriptableObject를 사용한다. 공격 종류는 기존 AttackType(Ranged/Melee)을 유지한다. 원거리는 Beam/ Ballistic/ Explosive, 근거리는 Edged/ Blunt로 나눈다. 분류 자체는 추가 공격 효과를 주지 않는다. Inspector에는 해당 종류의 분류만 표시한다.

| 필드 | 의미 |
|---|---|
| DisplayName | 표시 이름. 공백이면 에셋 이름 |
| AttackType / Category | 공격 종류와 해당 분류 |
| MinDamage / MaxDamage | 양 끝을 포함하는 정수 피해. 1 이상, 최대는 최소 이상 |
| BaseHitChance | 0~100 정수 |
| Range | 1 이상, 맨해튼 거리 |
| APCost | 1 이상 |
| WeightTonnes | 0 이상의 유한 소수, 톤(t). 이번에는 저장만 |
| GripRequirement | OneHandOnly / TwoHandsRequired / Either |
| TwoHandHitMultiplier | Either를 양손으로 잡았을 때 적용. 1 이상의 유한 배율 |
| DistanceBands | 원거리 거리 구간의 최대 칸 수와 명중 배율 목록 |

DistanceBands는 최대 거리 기준으로 오름차순이며 상한은 중복되지 않는다. 각 상한은 1~Range, 배율은 0 이상의 유한 값이다. 첫 구간은 거리1부터, 다음 구간은 이전 상한+1부터 포함한다. 목록 전체가 비었거나 마지막 구간 이후 남는 사거리는 ×1.0이다. 잘못된 목록은 Inspector에 오류를 표시하고 해당 무기로 공격을 허용하지 않는다. 근접무기는 거리 목록을 숨기고 계산에서도 무시한다. 유효하지 않은 enum 역시 사용을 거절한다.

샘플 초기값은 원거리 피해4~6/명중80/사거리7/AP3, 근거리 피해7~9/명중95/사거리2/AP3이다. 원거리 샘플은 Beam/Either, 양손 배율1.1, 거리 상한2/5/7과 배율0.9/1.0/0.8을 사용한다. 근거리 샘플은 Edged/OneHandOnly다. 중량은 미설정 초기값0t로 둔다. 이들은 사용자가 수정할 수 있는 검증용 시작값이며 최종 밸런스로 확정하지 않는다.

## 장착 책임

UnitWeaponLoadout은 시작 장착만 소유한다. 왼손과 오른손에 각 WeaponData 참조 및 GripMode(OneHand/TwoHands)를 둔다. 별도 수납 목록이나 전투 중 교체 API는 만들지 않는다. 이번에는 방패 슬롯 데이터도 구현하지 않는다.

양손 무기는 한쪽 슬롯에만 참조하고 해당 슬롯의 파지를 TwoHands로 설정한다. 반대 슬롯은 비어 있어야 한다. 반대 손은 점유 표시만 하며 두 번째 무기로 열거하거나 중량을 중복 계산하지 않는다. 같은 에셋을 두 손에 각각 한손으로 지정한 경우는 서로 다른 두 자루이며 슬롯으로 구분한다.

OneHandOnly+TwoHands, TwoHandsRequired+OneHand, 양손 점유 충돌은 전체 장착 오류다. 전체 장착 오류이면 어느 무기도 공격하지 못하며 자동 수납·자동 해제·모드 자동 변경은 하지 않는다. 컴포넌트가 있으나 비어 있으면 비무장이다. 비활성화된 컴포넌트도 기존 무기로 되돌리는 통로가 되지 않는다.

## 기존 자산 호환

UnitWeaponLoadout이 없는 기존 기체는 UnitCombat에 저장된 근접/원거리 수치를 계속 사용한다. 피해는 기존 값과 같은 최소=최대, 파지·거리 배율은1이다. 기존 씬·프리팹의 수치를 자동으로 바꾸지 않는다. 명시적으로 새 Loadout을 추가한 기체만 새 장착 경로를 사용하며 잘못된 설정은 기존 수치로 대체하지 않는다.

기존 Configure/ConfigureMelee는 이전 수치 경로만 수정한다. Loadout이 있는 기체의 공격 설정이나 공유 에셋을 조용히 변경하지 않는다. UnitCombat은 장착된 공격을 기존 전투 시스템에 제공하는 어댑터다. 공격자는 읽기만 하며 피해 추첨·AP 소비로 WeaponData를 수정하지 않는다.

## 명중과 피해

거리와 양손 배율은 기본 명중률에 먼저 곱한다. 기존 기동 회피는 기존처럼 정수 차감하고, 나머지 기존 배율을 적용한다.

FinalHit = round(clamp(max(0, BaseHit × GripMultiplier × DistanceMultiplier - MovementEvasion) × HeadMultiplier × PartMultiplier × CoverMultiplier, 0, 100))

중간 반올림이나100 상한 적용은 하지 않고 마지막에만 기존 반올림 규칙을 적용한다. 근접은 거리 배율1, 기존 엄폐/부위 조준 무시 규칙을 유지한다. 양손 필수 무기는 기본 명중률에 양손 사용 특성이 포함된 것으로 보고 파지 보너스를 추가하지 않는다. 겸용 무기의 TwoHands만 설정 배율을 받는다.

미리보기는 무기 이름·최종 명중률·최소~최대 피해·AP를 표시하고 난수를 소비하지 않는다. Fire에서 유효성을 다시 확인하고 AP 소비 후 명중을 추첨한다. 명중했을 때만 정수 피해를 한 번 추첨하여 기존 부위 피해 처리에 전달한다. 빗나감/공격 거절은 피해 난수를 소비하지 않는다. 실제 DamageDealt는 기존처럼 남은 부위 HP로 제한된 결과다. 거리별 피해는 없다.

## 입력과 AI

Attack → Melee/Ranged 흐름을 유지한다. 해당 종류의 무기가 하나이면 바로 선택한다. 둘이면 옆 확장 목록에서 손 이름과 무기 이름을 구분해 선택한다. 종류에 무기가 없으면 버튼 비활성화. 무기 선택 후 기존 적 선택·원거리 부위 조준·Fire 흐름을 따른다. 같은 종류의 두 무기를 선택하는 것은 손에 이미 든 공격 수단을 고르는 것이며 교체 AP가 없다. 선택 변경 시 조준과 이전 결과를 정리하고 범위/미리보기를 새 무기로 갱신한다.

AI는 기존 근접 우선·가까운 발견 대상 우선 정책을 유지한다. 같은 종류는 오른손→왼손 순서에서 실행 가능한 무기를 찾는다. 이동 계획은 실제 사용할 무기의 사거리와 AP를 사용하며 근접 전용 기체도 처리한다. 경로는 원거리면 사격 차폐, 근접이면 근접 도달 규칙을 따른다. 무기가 없거나 장착이 잘못되면 AP 소비 없이 대기한다. 새 표적 평가·기대 피해 최적화는 추가하지 않는다. 기존 시야 상실 취소 규칙은 유지한다.

## 사용 흐름

Create → MechaXCOM → Weapon Data로 생성하거나 기존 에셋을 Duplicate한다. 기체에 UnitWeaponLoadout을 추가하고 왼손/오른손과 파지를 설정한다. Inspector는 오류 및 양손으로 점유된 반대 손을 표시한다. 사용자 안내 문서와 샘플 에셋 두 개를 제공한다. 실제 모델은 기존 프리팹을 그대로 사용한다.

## 제외 및 보존

전투 중 교체·수납·파지 전환, 방패 효과, 탄약, 적재 한도·중량 합계·이동 보정, 거리별 피해, 폭발 범위·곡사·좌표 조준, 팔 파괴에 따른 무기 제한, 양손 모델 자세는 제외한다. Explosive도 현재 단일 대상 공격이다. 폭발 반경 필드는 실제 범위 공격 설계 때 추가한다.

사용자가 조정한 zoomSpeed60f, movementSpeed12f, 카메라 이동속도, Shadow Max Distance, 맵 크기·배치, 무기 손잡이·총구·모델 설정을 보존한다. 기존 씬·프리팹·머티리얼·Art/Models·Assets/Settings는 이번에 재저장하지 않는다. 새 자산과 런타임 테스트 객체만 사용한다. Git 저장소를 새로 만들지 않는다.

## 검증 범위

다섯 분류의 에셋 생성·복제·직렬화, 숫자·거리 구간 검증, 손 점유/파지 오류, 두 자루/양손 구분, 공유 에셋 불변성, 기존 수치 호환을 검증한다. 명중 배율의 순서와 거리 경계, 랜덤 피해 양 끝 포함 및 난수 소비 횟수, UI 실제 클릭과 선택 초기화, AI 무기별 사거리·AP·근접 전용·비무장 대기를 검증한다. 전체 EditMode/그래픽 PlayMode와 보호 파일 해시로 기존 공격·부위·시야·안개·카메라 회귀 및 원본 보존을 확인한다.
