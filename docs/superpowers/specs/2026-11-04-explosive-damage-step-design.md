# 폭발 부가 피해의 무기별 추첨 간격

사용자 승인: 부가 피해 배율을 연속값 대신 지정한 간격의 값 중에서 같은 확률로 뽑는다. 간격도 무기별 WeaponData에서 따로 설정한다. 예: 최소0%, 최대20%, 간격5%p이면0/5/10/15/20%에서 각 부위마다 독립 추첨한다. 최소·최대값을 간격의 배수로 제한하는 앞선 제안을 따른다.

간격은 Inspector에서 정수 퍼센트포인트1~100, 기본5로 설정한다. 기존 최소/최대 배율 필드(0~1)는 유지하며 예를 들어0.05는5%다. 기존 에셋에 새 필드가 없으면5를 사용한다. 간격에 맞지 않는 최소·최대값은 자동 변경하지 않고 유효성 검사와 Inspector 오류로 알린다. 반올림에 의한 float 표현 오차만 허용한다.

기본 추첨은 허용 단계 수를 경계로 하는 정수 난수로 수행하여 양 끝값도 동일한 확률로 선택한다. 정수 퍼센트에서 최종 정수 피해를 계산한다. 기존 테스트용 비율 난수 주입 API는 호환 유지하되 반환값을 허용 단계로 양자화해 단계 규칙을 우회하지 못하게 한다. 별도 단계 인덱스 난수 주입 API를 제공해 실제 공격에서 각 단계와 자원 소모를 검증한다.

추가 부위 선택·콕피트/직격/파괴 부위 제외·단일 명중/치명타·HP 절단 전 기준·일괄 상태 판정·AP/탄약 규칙은 유지한다. 곡사·범위 공격·기존 에셋 수정은 제외한다.
