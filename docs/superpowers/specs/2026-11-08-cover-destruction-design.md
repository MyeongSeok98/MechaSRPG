# 엄폐물 내구도와 폭발무기 파괴

사용자 승인: 프리팹 CoverDurability에서 최대HP 지정, 0이면 완전히 파괴되어 기능 상실. 추가 답변으로 직사·곡사 무기 피해 연결까지 함께 구현한다. 직사는 엄폐물 직접 선택→HP/예상피해→Fire, 기체 선택은 기존 부위 공격. 곡사는 기존 좌표 중심 마름모 범위의 기체와 엄폐물을 함께 타격한다.

CoverDurability는 개체별 HP/피해/파괴만 관리한다. 기본 최대HP1000(초기값, 조절 가능), 전투 개체별 초기화, 재활성화로 회복하지 않는다. HP0이면 루트를 비활성화하여 모델/자식/충돌을 제거한다. CoverObject/CoverSystem은 엄폐 제공과 지도 갱신을 맡는다. 내구도 없는 기존 엄폐/큰 건물은 파괴 불가다. Half/Full과 HP는 독립이다.

HalfCover/FullCover 프리팹에 컴포넌트를 추가한다. 모델/콜라이더/크기/위치/재질은 변경하지 않는다. 프리팹 연결 없는 저장 씬의 독립 엄폐에는 자동 부착하지 않는다. 사용자는 그런 오브젝트에 CoverDurability를 붙일 수 있다. 기존 씬/무기 에셋/속도/카메라/그림자/엄폐 배율은 보존한다.

WeaponData에 엄폐물 피해 배율(기본1, 유한한0이상)을 둔다. 기존 최소~최대 피해를 엄폐물마다 한 번 추첨하여 배율을 곱하고 마지막에 정수 반올림/상한 처리한다. 부위 피해 합산/파일럿/치명타/장갑 보정은 엄폐물에 적용하지 않는다. 배율0은 엄폐 피해 없음. 동일 폭발로 다칸 엄폐물을 여러 번 때리지 않는다.

직사 엄폐 공격은 원거리/폭발물/직사 무기만 사용한다. 정상 자기 턴·AP·탄약·등록된 그리드/엄폐·사거리·건물 사선을 검증하고 정적 엄폐에는 확정 명중한다. AP/탄약은 한 번만 소모하고 미리보기는 RNG/자원 무소모다. 기체를 겨냥한 직사 공격은 기존대로 기체만 피격한다. 경계사격의 엄폐 타격과 직사AI의 엄폐물 선택 전략은 이번 범위에 없다.

곡사 대상은 피해 적용 전에 기체/엄폐 모두 확정한다. 엄폐 파괴로 열린 경로를 같은 발에 다시 탐색하지 않는다. 벽의 첫 피격면은 피해를 받되 뒤쪽 폭발은 막힌다. 자기 자신 목표 엄폐의 종점 차단만 면제하고 겹치는 다른 건물은 관통하지 않는다. 미탐지 기체 피해/결과 정보 보호·아군 피해·곡사 특성/발사 제한은 유지한다. 곡사 AI의 기존 발사는 엄폐 피해도 함께 적용한다.

그리드는 등록 콜라이더별 점유 기여를 추적해 하나를 제거해도 겹치는 장애물/다른 엄폐/수동 이동불가/기체 점유를 보존한다. 재등록은 중복 누적하지 않는다. 파괴 후 방향별 엄폐·이동·사선·시야/FOW·이동/공격 표시를 갱신한다. HP0 상태는 재등록/활성화로 복구하지 않는다.

구현은 기존 구조를 확장하며 별도 지형 데이터/파괴물 물리/잔해/부분 파괴/건물 붕괴 시스템은 만들지 않는다. Git 작업 금지. 테스트는 기존 복제본만 사용한다.
