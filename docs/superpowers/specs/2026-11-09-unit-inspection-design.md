# 아군·적 기체 정보 선택

요청: 적도 클릭해서 기체명, 부위별 현재/최대 HP, 장착 무기, 외형을 확인한다. 선택된 아군은 초록, 적은 빨간 외곽선 사각형으로 표시한다. 기존 진영별 턴·공격 조준·시야 규칙을 유지한다.

방식: 기존 PlayerInputController의 선택을 양 진영으로 확장하고 행동 권한은 명시적으로 아군만 허용한다. 기존 왼쪽 BattleDebugUI에 기체명/장착 무기/실제 모델 미리보기를 추가한다. 별도 선택 시스템/정보 창을 만들지 않아 UI 차단 영역과 해제를 공유한다. 공격 준비 상태에서 적 클릭은 기존 조준을 우선한다.

기체명은 MechaData.DisplayName, HP는 UnitHealth 현재 상태, 무기는 UnitWeaponLoadout의 좌/우/백팩을 읽는다. 양손 파지 무기는 한 번 표시한다. 외형은 선택한 실제 렌더러의 메시/재질을 별도 RenderTexture에 그린다. 전투 오브젝트를 복제하거나 씬 카메라/레이어/콜라이더를 변경하지 않는다. 원래 모델/무기 배치와 색상을 유지하고 미리보기는 무조명 재질로 읽기 쉽게 보여준다.

적은 플레이어 진영에 현재 탐지되고 등록된 살아있는 기체만 선택한다. 시야 상실·파괴·ESC·허공 클릭 시 정보와 선택 테두리를 제거한다. 적 선택은 이동·공격·재장전·경계·탈출 권한을 주지 않는다. 다른 유닛의 행동/방향 확정/경계 결정 중 선택 차단은 유지한다. 기존 적 행동 중 빨간 테두리도 유지한다.

선택 색상은 런타임 소유 재질로 지정하며 기존 저장 재질을 수정하지 않는다. 두 저장 씬에 코드로 적용하고 씬·데이터·프리팹·카메라·이동 속도·전투 수치는 변경하지 않는다. 이번 요청에 Git 작업은 포함하지 않는다.
