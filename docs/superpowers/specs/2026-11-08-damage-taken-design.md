# 기체별 실탄·빔 받는 피해율

승인 범위: MechaData Inspector에 실탄 받는 피해(%)와 빔 받는 피해(%)를 50~150 정수 슬라이더로 노출한다. 새 기체의 기본값은 100이며 낮을수록 강하다. 일반/대빔/대실탄 타입을 선택하는 기존 UI를 대체한다. 기존 타입 보정과 중복 적용하지 않는다. 근접/직사 폭발/곡사 폭발은 기존대로 이 배율을 적용하지 않는다.

기존 에셋을 수정하지 않고 보존하기 위해 armorType은 숨겨진 호환 데이터로 남긴다. 새 필드는 내부값 -1일 때만 기존 타입의 100/80/110을 읽는다. -1은 Inspector에서 선택할 수 없는 레거시 표식이다. 사용자가 슬라이더를 편집하면 50~150을 명시 저장하므로 기존 타입에 우선한다. null MechaData는 100/100이다. 기체 초기화 때 두 기본값을 개별 BattleUnit에 복사하여 공유 에셋 변경이나 재초기화로 전투 중 변하지 않는다.

전투의 기존 ArmorMultiplier 자리에는 BattleUnit.GetDamageTakenMultiplier(type, category) 최종 함수 결과를 한 번 적용한다. 기본값과 최종 조회 지점을 분리하여 추후 추가부품의 보정을 이 함수에 연결할 수 있게 한다. 이번에는 부품/장착/패시브/보정 재고를 구현하지 않는다. UI 피해 미리보기, 일반/경계/AI 사격, 치명타/파일럿 배율과 정수 반올림은 기존 공통 경로를 유지한다.

원본 씬/무기/모델/속도/카메라/장갑 타입 에셋을 변경하지 않는다. Git 관련 작업은 하지 않는다.
