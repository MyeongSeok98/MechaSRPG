# 공격 결과 팝업 설계

승인된 흐름: 플레이어·AI·경계사격 모두 피해를 즉시 계산하고 대상 위에 약 0.8초 팝업을 띄운 뒤 다음 행동으로 진행한다. 부위/피격 문구는 영어로 표시한다. Head, Body, L.Arm, R.arm, L.Leg, R.Leg, C.Pit를 사용한다. 조준창/디버그의 공통 부위명도 통일한다.

접근: 전투 결과 이벤트 → 독립 CombatFeedbackPresenter → TurnManager의 일시적 행동 대기. 개별 UI에서 지연시키면 AI·경계 경로가 빠지므로 공통 전투 완료 지점에 연결한다. 피해 계산 자체를 코루틴으로 바꾸지 않아 기존 API와 자원/무작위 판정을 유지한다.

직사·근접·직사 폭발 부가 피해·곡사·엄폐물 공격을 포함한다. 한 대상의 부위 피해는 한 팝업의 여러 줄로, 곡사 대상은 동시에 표시한다. MISS, HIT, CRITICAL!, 부위 DESTROYED를 사용한다. 실제 HP 감소량을 표시한다. 죽은 대상은 피해 직전 위치에 계속 표시한다. 미탐지 적은 공격 전 플레이어 시야를 기준으로 숨기며 아군은 항상 표시한다.

BattleSceneController가 런타임에 표시기를 연결한다. 카메라 없는 순수 전투 API/테스트에는 표시 지연을 만들지 않는다. 유효한 표시가 있을 때만 행동 잠금을 건다. 피해 계산 중 전투 종료 판정을 보류하고, 마지막 팝업이 끝난 뒤 종료한다. 경계 이동/다음 사수 결정도 대기한다. 표시기 비활성화/파괴 시 잠금을 해제한다. 시간은 unscaled time을 사용한다. 카메라 이동은 허용한다.

HP/AP/Ammo의 Oxanium 설정을 유지하고 팝업 전체에는 기존 기본 폰트를 쓴다. 씬·데이터·수치·카메라·배치와 Git은 수정하지 않는다. 고정 이미지에 인쇄된 부위 이름은 변경하지 않는다.
