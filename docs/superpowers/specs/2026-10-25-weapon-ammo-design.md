# 유한 탄창/에너지 팩과 재장전

## 확정 범위
빔은 에너지 팩, 실탄은 탄창을 사용한다. 사용자는 재장전 시 잔탄을 버리고 예비 1개로 완전히 교체하는 방식을 선택했다. 무기별 장탄 수/예비 개수/재장전 AP를 지정하고 기존 발사 AP를 유지한다. 장전 1개+예비2개로 시작하며 자동 충전/턴별 탄약 회복은 없다.

## 동작
- 모든 원거리 무기의 공통 탄약 기능이다. 빔은 팩, 실탄/폭발물은 탄창으로 표시한다. 근접은 탄약을 사용하지 않는다. 사격 1회에1발, 명중/빗나감 동일 소모. 실패한 공격/조준/Skip은 소모하지 않는다.
- WeaponData에 magazineCapacity(기본6), spareMagazineCount(기본2), reloadAPCost(기본3)를 추가한다. 모두 무기별 편집 가능. 기존 apCost는 발사 비용으로 유지한다. 빔/실탄 간 수치 차이는 개별 에셋에서 설정하며 종류만 바꿨다고 값을 자동 덮어쓰지 않는다.
- 잔탄과 예비 개수는 UnitWeaponAmmo가 각 기체의 각 장착 무기별로 관리한다. 같은 WeaponData를 공유해도 탄약을 공유하지 않는다. 같은 손의 무기 유지/파지 변경/반대 손으로의 자동 이동은 탄약을 보존한다. 무기 정의 교체는 새 장착 상태로 취급한다. 런타임 인벤토리 교체 기능은 추가하지 않는다.
- 재장전은 자기 턴, 정상 행동 가능, 유효 무장/팔, AP 충분, 탄창이 덜 찼고 예비가 있을 때만 가능하다. 즉시 AP 소모 후 잔탄 폐기, 만탄 장전, 예비1차감. 실패하면 자원 변경 없음. Critical/파괴/탈출/이동/방향선택/경계 중에는 불가.
- 일반 사격/경계사격은 추첨/콜백 전에 탄약을 차감한다. 경계 진입에는 탄약이 필요하며, 마지막 탄 발사 이후 경계는 종료되어 다음 적을 붙잡지 않는다. 경계 중 재장전/자동 재장전은 없다. 기존 경계사격의 추가 발사 AP0은 유지한다.
- 적 AI는 즉시 가능한 공격을 우선한다. 탐지한 적이 있으나 즉시 공격하지 못하고 빈 원거리 무장이 있으면 가능한 무기1개를 재장전한 후 남은 AP로 기존 판단을 수행한다. 적이 보이지 않으면 기존 대기를 유지한다. 탄창/예비가 모두 없으면 다른 무장을 사용하거나 대기한다.
- 유닛 메뉴에 Reload 추가, 옆 메뉴에서 장착 무기 선택. 탄약/예비/AP 표시. 조준창/디버그에도 탄약 표시. ESC는 기존처럼 선택 취소.

## Approaches
공유 WeaponData에 현재 탄약을 저장하면 같은 무기를 쓰는 유닛들이 자원을 공유하게 된다. 따라서 WeaponData는 정의만, 별도 UnitWeaponAmmo는 인스턴스 상태만 담당한다. 원거리 종류별 별도 컴포넌트는 중복이므로 만들지 않는다.

## 보존/검증
Git/GitHub 금지. 기존 씬 배치/맵/모델/속도/카메라/HP/피해/발사AP는 보존한다. 기존 에셋은 코드 기본값으로 새 탄약 필드를 제공한다. 신규 패키지/탄약 인벤토리/반환한 반쪽 탄창/연사별 소모/중량/캠페인 보급은 추가하지 않는다. 기존 격리 Unity 프로젝트에서 TDD, 전체 EditMode/graphicsPlayMode, 새 재장전 UI/AI/경계/팔 파괴 회귀를 검증한다.
