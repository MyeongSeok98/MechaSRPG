# 무기 특성 목록과 곡사 발사 경로

대화에서 승인한 설계를 구현한다. WeaponTrait enum과 WeaponData의 직렬화 목록, HasTrait 함수를 사용한다. 첫 특성은 `IndirectOverBuildings = 0` (건물 너머 곡사 가능) 하나다. 별도 특성 에셋, 가상 효과 클래스, 파일럿 패시브는 만들지 않는다.

기본 목록은 비어 있다. 기존 곡사무기도 특성을 명시하지 않으면 발사 기체부터 착탄점까지 큰 건물이 막는 좌표를 조준/발사할 수 없다. 기존 GridObstacle.BlocksShots 판정을 재사용한다. 일반 Half/Full Cover, 이동만 막는 골짜기, 다른 기체는 발사 경로를 막지 않는다. 선분이 모서리를 통과할 때 양옆 칸도 검사하는 기존 그리드 규칙을 유지한다. 특성이 없는 무기는 건물 칸 자체에도 착탄점을 지정할 수 없다.

특성이 있는 곡사 폭발무기는 발사 경로의 건물 차단만 무시한다. 맵 경계와 기존 맨해튼 사거리를 지킨다. 다른 공격 종류는 특성이 있어도 기존 차단 규칙을 유지한다. 건물 높이/실제 포물선 계산은 하지 않는다.

공격 범위 표시, 조준 미리보기, Fire 확정, 적 AI는 동일한 곡사 착탄점 검증을 사용한다. Fire 시 재검증하고 차단된 발사는 AP/탄약/RNG를 소모하지 않는다. 곡사 경계사격 제외, 미탐지/아군 피격, 마름모 폭발 범위는 유지한다.

착탄점→대상의 폭발 차단은 기존 HasClearBlast를 그대로 사용한다. 특성으로 폭발이 건물을 관통하지 않는다. 기존 특성 무기의 건물 칸 착탄 후 폭발 처리도 유지한다.

Inspector에는 한글 특성 목록과 적용 범위를 설명한다. 목록의 알 수 없는 enum 값과 중복은 유효하지 않은 데이터로 표시한다. null은 빈 목록으로 처리한다. 기존 씬/에셋/프리팹 수치를 수정하거나 특성을 자동 부여하지 않는다. 엄폐물 HP/파괴 기능은 별도 범위다.
