# 모든 무기의 시설 피해

사용자 요청은 통신소 등 시설 목표가 빔·실탄·폭발·근접무기에 모두 피해를 받게 하는 것이다. DestructibleObjectData가 연결된 CoverDurability를 시설로 구분한다. 데이터 없는 일반 엄폐물은 기존 폭발무기 전용/무기별 엄폐물 피해 배율을 유지한다. 기존 씬·데이터·튜닝·Git을 수정하지 않는다.

시설 직접 공격은 무기의 기본 정수 피해 범위를 사용한다(시설에는 엄폐물 피해 배율을 적용하지 않음). 기존 시설 규칙대로 확정 명중, 치명타/기체 부위 보정 없음. 원거리는 Manhattan 사거리·사선·AP·탄약, 근접은 동일 사거리 안의 짧은 통행 가능 경로·AP를 검사한다. 근접은 탄약 컴포넌트가 없어도 실행 가능하다. 대상 시설 자신의 점유만 마지막 칸에서 허용하고 다른 건물/유닛/골짜기를 우회 없이 무시하지 않는다.

PlayerInputController는 모든 직사/근접무기로 시설을 클릭해 조준하고 확정할 수 있게 한다. 공격 가능 범위/미리보기/실행이 같은 도달 조건을 사용한다. 근접 UI에는 탄약0/0 대신 AP만 표시한다. 기존 곡사는 좌표 조준을 유지하고 시설은 기본 피해, 일반 엄폐물은 기존 배율을 적용하며 미리보기에도 구분한다. 무기의 엄폐물 배율0이 시설까지 면역으로 만들지 않게 한다.

피해 팝업·사선/엄폐 제거·임무 성공·원자적 피해/팝업 대기 흐름은 재사용한다. 시설 AI 타깃 선택/경계사격 확장은 포함하지 않는다. 테스트는 기존 복제본에서만 수행한다.
