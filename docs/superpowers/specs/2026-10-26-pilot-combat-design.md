# 파일럿 사격·근접·회피 전투 연결

사용자가 2026-10-26 제안한 수치를 승인하고 적용을 요청했다.

- 원거리 명중 배율: `1 + (사격 - 대상 회피) × 0.01`.
- 근접 명중 배율: `1 + (근접 - 대상 회피) × 0.005`.
- 근접 피해 배율: `1 + 공격자 근접 × 0.005`. 원거리 피해는 ×1.
- 각 능력치를 전투 시작 시 0~50으로 제한하여 BattleUnit에 복사한다. 파일럿 미지정은 0. 공유 CharacterData 및 기존 에셋 수치를 변경하지 않는다.
- 기체 명중/회피 배율과 별도로 파일럿 배율을 곱한다. 최종 명중률만 0~100 제한·반올림한다. 근접 피해도 원래 무기 피해 정수를 뽑고 장갑·치명타·파일럿 배율을 모두 곱한 뒤 한 번 반올림한다.
- 일반 공격, 적 AI, 경계사격은 공통 CombatSystem 경로로 적용한다. 미리보기 피해 범위와 실제 피해가 일치해야 한다. 기량의 치명타 규칙은 유지한다.

## 접근 방식
기존 CombatMath와 CombatSystem을 확장하는 방식을 선택한다. 별도 파일럿 전투 서비스나 패시브로 구현하는 방식은 현재 고정 능력치 3개의 연결에 불필요한 중복 경로를 만든다. BattleUnit은 초기화, CombatMath는 순수 계산, CombatSystem은 보정 수집, Presentation은 결과 표시 책임을 유지한다.

## 범위와 제약
성장·패시브·이동·기체/무기 밸런스·씬 편집은 포함하지 않는다. Git/GitHub 작업 금지. 사용자 설정/배치/모델/이동속도/카메라/그림자 보존. Unity 실행은 기존 Artifacts/MeleeRangedTestProject 복제본에서만 수행한다.
