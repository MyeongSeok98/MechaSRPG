# 곡사 폭발 범위 마름모 전환

사용자 요청: 곡사 폭발 범위를 원형에서 마름모로 변경한다. 가로 차이 절댓값+세로 차이 절댓값≤폭발 반경, 경계 포함. 무기별 반경 값과 그 외 피해·차단·시야/정보 보호 규칙은 유지한다. 탐지 원형 범위는 변경하지 않는다.

Native / TDD / 기존 테스트 복제본만 Unity 실행 / Git 작업 금지.

- [x] 반경3에서 기존 원형에는 포함되지만 마름모에는 제외되는(2,2) 상대좌표와 경계(3,0)/(1,2)의 실제 피격 검사를 추가한다. 중심(4,4), 반경3은25칸이어야 한다. 기존 실제 마우스 좌표 선택 Play 검사도 반경3·표시25칸으로 강화하고 구현 전에 RED 확인.
- [x] CombatSystem.GetIndirectBlastCells의 거리 조건만 가로·세로 합산으로 변경한다. 범위 표시·미리보기·실제 피해가 모두 이 공통 경로를 사용한다. Inspector/안내/현재 설계를 마름모로 정리한다.
- [x] 새 경계 검사 및 전체 EditMode/그래픽 PlayMode를 복제본에서 검증한다. 기존 씬·프리팹·무기/기체 에셋·배치·속도·카메라·엄폐·설정은 유지한다.
- [x] 실행 스킬에 따른 fresh 읽기 전용 최종 리뷰1회, 중요 결함은 실패 재현 후 수정. 보호 파일 해시·원본/검증 복제본 C# 일치와 테스트 결과를 기록한다.

## 완료 결과

구현 전 EditMode와 실제 좌표 클릭 PlayMode에서 원형29칸과 목표25칸 차이로 실패한 것을 확인했다. 최종 전체 EditMode814/814, 그래픽 PlayMode395/395 통과(실패·건너뜀0). 테스트 실행은2026-11-04, 사용량 제한으로 중단된 읽기 전용 리뷰와 완료 기록은2026-11-05 재개하여 마무리했다. 리뷰 결과 조치할 결함 없음.

변경은 제품 C#2개와 테스트2개. 기존 씬·프리팹·에셋·맵 배치·카메라·속도·엄폐·프로젝트 설정은 기준 해시와 같으며, 원본 C#은 검증 복제본과 일치한다. 탐지 원형 판정과 건물 폭발 차단은 그대로 유지했다. Git 작업 없음.
