# 기체별 예비 탄약과 탄창 중량

승인된 범위: 예비 탄창/팩 개수는 기체의 UnitWeaponLoadout에서 선택한다. WeaponData는 빈 무기 중량, 만탄 탄창/팩 하나의 중량, 장탄 수와 재장전 AP를 정의한다. 기존 예비 개수는 호환용 권장 기본값으로 남긴다. -1 설정은 이 기본값을 사용하며 전투 초기화 때 기체별로 확정한다.

B 방식: 손 무기 중량 = 빈 무기 + (장전 1개 + 선택 예비 개수) × 탄창 중량. 백팩은 자체 중량 + 포함 무기 본체 + 장전 1개이며 예비는 0개다. 근접은 탄약 무게가 없다. 장착 한도는 출격 구성 중량으로 검사하며 전투 중 잔탄에 따라 감소하지 않는다. 기존 에셋은 새 탄창 중량 기본 0으로 보존한다.

전투 중 현재 탄약은 UnitWeaponAmmo가 관리한다. 파지 변경/손 이동/턴 초기화로 탄약이 복구되지 않는다. 기체별 예비 개수 변경은 전투 시작 전에만 허용한다. 인벤토리/보급/이동력 감소는 범위 밖이다.
