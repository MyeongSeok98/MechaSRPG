## Task 1: 단일 상태 판정 배치 피해

- [x] PartDamageBatchTests를 먼저 작성한다. HP 모두 반영 후 콜백, 직격 치명 부위 파괴 이후에도 부가 HP 반영, 3/4개 파괴 및 기존 Critical 재피격의 최종 판정1회, 중복 이벤트 방지, 빈/무효 입력·탈출 상태를 검사한다.
- [x] 복제본에서 RED를 확인한다. PartDamage 입력 구조와 UnitHealth.ApplyDamageBatch를 추가하고 기존 ApplyDamage는 같은 내부 경로를 사용하게 한다. 기존 단일 피해 결과·이벤트 순서를 유지한다.
- [x] 배치 검사와 기존 MechPartHealthTests/손상·탈출 회귀를 실행해 GREEN을 확인한다.

## Task 2: 무기 데이터·공통 공격·안내

- [x] ExplosivePartDamageTests를 먼저 작성한다. 데이터 기본값/검증/저장, 후보 제외·중복 없음·부족 처리, 독립 비율·0%, HP 절단 전 기준·치명 보정1회, 빗나감/거부/미리보기의 RNG·자원 보존, 비폭발·근접 호환을 검사한다. 새 필드/API가 없으면 reflection 검사로 명확히 실패시킨다.
- [x] WeaponData/WeaponDataEditor에 추가 부위 수와 비율을 추가한다. 수0은 비활성, 비율 기본.05~.15. 기존 에셋을 바꾸지 않는다.
- [x] CombatSystem 공통 ExecuteAttack에서 명중 시 후보를 먼저 선택하고 모든 피해를 배치로 전달한다. 선택/비율 RNG를 주입 가능하게 하고 추가 명중·치명·AP·탄약 소모는 하지 않는다. AttackResult는 직격 결과를 유지하면서 추가 부위별 결과를 제공한다.
- [x] AttackPreview에 최대 개수/비율을 담고 기존 BodyTargetUI/DebugUI에 미리보기와 부가 피해 결과를 표시한다. 추가 정보가 있을 때만 패널 높이와 하단 버튼을 같은 양만큼 확장한다.
- [x] 그래픽 PlayMode에서 플레이어 부위 선택/Fire 결과·표시, AI 공통 피해, 백팩 경계 Fire/Skip·마지막 탄환 이동 해제를 검증한다. 테스트를 먼저 실행해 추가 피해 부재로 실패함을 확인한다.
- [x] 기존 테스트 복제본에서 전체 EditMode/그래픽 PlayMode를 실행한다. Unity 종료 후에만 동기화하고 신규 meta만 원본에 복사한다. 이전 해상도 복원 간헐 오류/엔진 종료 오류는 실패 근거를 보존하고 제품 설정을 수정해서 숨기지 않는다.
- [x] Fresh 읽기 전용 최종 리뷰1회. 중간 파괴 이벤트·후보 추첨 시점·일관된 치명/반올림·미리보기 RNG 소비·일반/AI/경계 공통 경로를 검토한다. 중요한 발견은 실패 재현 후 수정하고 전체 회귀를 다시 실행한다.
- [x] 무기 사용 안내/README/체크리스트 갱신, 기존 씬·프리팹·에셋·속도·카메라·엄폐·설정 해시 보존, 검증 소스 일치 및 실제 테스트 결과를 기록한다.
