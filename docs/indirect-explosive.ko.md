# 곡사 폭발무기 사용 안내

곡사는 적의 특정 부위를 조준하지 않고 맵 좌표를 골라 마름모 범위의 기체에 확정 피해를 주는 공격입니다. **아군·자신·미탐지 적도 맞습니다.** 실제 피해는 무기별 최소~최대 피격 부위 수와 최소~최대 피해로 결정합니다.

## 무기 데이터 설정

WeaponData를 새로 만들거나 기존 무기를 복제한 뒤 다음 값을 지정하세요.

| 항목 | 설정 |
|---|---|
| 공격 종류 | Ranged |
| 원거리 분류 | Explosive |
| 공격 방식 | 곡사 · 좌표 지정 |
| 무기 특성 | 큰 건물을 넘어 발사하려면 `건물 너머 곡사 가능` 추가. 빈 목록은 건물에 막힘 |
| 사거리 | 중심 좌표를 고를 수 있는 가로·세로 합산 거리 |
| 폭발 반경 | 중심부터 가로·세로 거리의 합으로 계산하는 마름모 반경. 1칸 이상 |
| 최소·최대 피격 부위 수 | 각 기체가 맞을 부위 수. 1~6, 최소≤최대 |
| 최소·최대 피해 | 선택된 각 부위가 받는 정수 피해 범위 |
| 공격 AP·장탄 수·재장전 AP | 기존 무기 설정 사용. 실제 예비 개수는 기체별 UnitWeaponLoadout에서 설정 |

예: 반경2칸, 피격 부위1~3개, 부위당 피해100~200. 각 기체가1~3부위를 독립적으로 추첨하고 각 부위의 피해도100~200에서 따로 추첨합니다. 이 숫자는 예시이며 자동 적용한 밸런스가 아닙니다.

공격 방식 필드가 없는 기존 에셋은 기본 직사로 읽힙니다. 곡사 필드의 초기값은 반경1, 최소·최대 부위 수1입니다. 기존 씬·기체·무기 배치를 자동 변경하거나 샘플 무장을 교체하지 않았습니다. 사용할 무기 에셋을 직접 지정하고 전투를 다시 시작하세요.

## 플레이어 조작

1. 아군 선택 → Attack → `[곡사]` 무기 선택.
2. 붉게 표시되는 사거리 안에서 맵 좌표 클릭. 기체 위를 눌러도 해당 지면 좌표를 조준합니다.
3. 노란 폭발 범위와 확인된 대상·아군 피해 경고를 확인합니다.
4. 곡사 확인창의 **Fire / 포격 확정**을 누릅니다.

확인창의 취소는 조준을 취소하며, ESC는 기체 선택 자체를 해제합니다. 다른 무기/기체를 선택하거나 턴을 종료하면 준비 중인 좌표도 초기화됩니다. 이미 실행한 공격의 AP·탄약은 되돌리지 않습니다.

## 조준과 폭발 판정

- 사거리와 발사 경로 조건을 만족하면 시야 밖·미탐험·빈 칸도 조준할 수 있습니다. 자신의 칸도 선택할 수 있으므로 아군 경고를 확인하세요.
- 사거리는 기존 마름모 방식이며, 폭발 반경은 `|dx| + |dz| ≤ 반경`인 마름모입니다. 경계도 포함합니다.
- 기본 곡사무기는 발사점과 착탄점 사이의 큰 건물에 막힙니다. **건물 너머 곡사 가능** 특성이 있는 무기만 넘습니다. 범위 표시·조준·발사·AI가 같은 검사를 사용합니다. 건물은 GridObstacle의 Blocks Shots로 구분하며 일반 엄폐/골짜기는 발사를 막지 않습니다.
- 착탄점에서 피격 기체까지의 중간 건물은 폭발을 차단합니다. 기존 Grid의 코너 차단 규칙도 사용합니다.
- 해당 특성이 있으면 건물 칸 자체를 중심으로 지정할 수 있습니다. 이 경우 중심 칸은 폭발 출발점으로 취급하고, 이후 중간·대상 칸의 건물 차단을 검사합니다. 특성이 없으면 건물 칸 조준도 막힙니다.
- 반엄폐·완전엄폐 배율은 적용하지 않습니다. 범위 표시는 건물 차단을 반영한 피해 도달 칸입니다.

특성은 발사 경로에만 영향을 줍니다. 건물 너머로 발사해도 착탄점과 대상 사이의 건물은 폭발을 막습니다. 실제 포물선이나 높이 판정은 없으며 [무기 특성 안내](weapon-traits.ko.md)를 참고하세요.

## 피해·자원·부위

- 명중/치명타 판정이나 장갑·파일럿 피해 보정 없이 최소~최대 피해를 부위마다 그대로 추첨합니다.
- 진영에 관계없이 폭발 범위에 있는 기체가 피격됩니다. 미탐지 적도 실제 피해를 받습니다.
- 기체마다 피격 부위 수를 따로 추첨합니다. 최소=최대이면 고정 개수입니다.
- 콕피트·이미 파괴된 부위는 제외하고 중복 없이 선택합니다. 후보가 부족하면 가능한 부위만 공격합니다.
- 각 기체의 모든 HP를 적용한 뒤 Critical/Destroyed 상태를 한 번 판정합니다.
- 발사 기체가 먼저 파괴되더라도 그 한 발의 다른 기체 피해를 마저 적용한 뒤 전투 종료를 판정합니다.
- 대상 수·피격 부위 수에 관계없이 AP와 탄약은 한 발 기준으로 한 번만 소모합니다. 빈 지점 발사도 소모합니다.
- 백팩 곡사는 시작 잔탄만 사용하고 재장전할 수 없습니다. 손 무기의 재장전 규칙은 기존과 같습니다.
- 직사 폭발의 추가 부위 수·부가 피해 배율·%p 간격은 곡사에 사용하지 않습니다.

## 미탐지 정보 보호

미리보기와 플레이어용 공격 결과에는 아군과 발사 전에 탐지한 적만 표시합니다. 미탐지 적의 이름·위치·부위·피해 대상 수를 알려주지 않습니다. 결과의 ‘확인된 피격’은 화면에 알려줄 수 있는 기체 수이며 실제 피격 전체 수가 아닙니다. 미탐지 기체를 맞혔다고 자동 탐지하거나 안개를 걷지 않습니다.

## 적 AI와 경계

기본 AI는 발견한 적의 현재 칸을 중심으로 곡사를 사용할 수 있습니다. 아군이나 자신에게 폭발 피해가 예상되면 그 좌표로 발사하지 않습니다. 이동 후 발사할 자리를 찾을 때도 같은 곡사 발사 경로·특성 판정을 사용합니다. 여러 착탄점의 범위 피해를 비교하거나 곡사 전용 진지의 유불리를 평가하는 전술 AI는 없습니다.

곡사무기는 경계 선택 목록에서 제외하며 경계 진입 API에서도 거부합니다. 직사무기의 기존 경계·직사 폭발 피해는 유지합니다.

## 범위 밖 기능

탄착 오차·명중 실패·중심/가장자리 피해 감쇠·실제 포물선 발사체/폭발 연출은 포함하지 않습니다. 폭발에 의한 엄폐물 파괴는 추가 구현했으며 [엄폐물 내구도 안내](cover-destruction.ko.md)를 참고하세요. 범위 안의 각 엄폐물에 기본 피해를 한 번씩 추첨하고 엄폐물 피해 배율을 적용합니다. 피해 적용 전 대상을 확정하므로 벽이 파괴되어도 그 뒤의 기체가 같은 발에 새로 맞지는 않습니다. 노란 범위에는 실제로 맞는 엄폐물 표면 칸도 표시합니다.
