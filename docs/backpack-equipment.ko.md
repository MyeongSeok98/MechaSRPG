# 백팩 장착·무장 사용 안내

백팩은 포함 무장과 함께 교체하는 일체형 장비다. 기체당 백팩 하나를 장착할 수 있고, 무장 백팩에는 WeaponData 하나가 연결된다. 무장 없는 백팩과 백팩 미장착도 가능하다. 손을 점유하지 않으므로 양손 무기와 함께 사용할 수 있다.

## 샘플 연결

`Assets/_Game/Data/Backpacks/`에 다음 두 에셋이 있다.

| 에셋 | 포함 무장 |
|---|---|
| SampleUnarmedBackpack | 없음. Attack/Overwatch 목록에 추가 무기를 만들지 않음 |
| SampleWeaponBackpack | 기존 FixedRanged_5_80_7_3 WeaponData를 참조하는 원거리 샘플 |

기존 씬에는 자동 장착하지 않았다. 직접 확인하려면 다음 순서로 설정한다.

1. Play를 중지하고 `1V1Test` 또는 `SqurdWeaponTest` 씬을 연다.
2. 시험할 유닛의 `Unit Weapon Loadout`에서 **장착 백팩**에 `SampleWeaponBackpack`을 연결한다.
3. Inspector의 읽기 전용 **백팩 포함 무장**과 **총 장착 중량**을 확인한다. 손 무기와 파지 설정은 유지한다.
4. Play를 시작하고 해당 아군을 선택한 뒤 `Attack`을 누른다.
5. `Backpack: FixedRanged_5_80_7_3`을 선택한다. 탐지된 사거리 내 적과 부위를 고르고 `Fire`로 확정한다. 이 무기의 실제 성능은 파일 이름의 과거 숫자 대신 연결된 WeaponData Inspector를 기준으로 한다.
6. 백팩 잔탄이 줄고 손 무기의 잔탄은 유지되는지 확인한다. 백팩은 `Reload` 목록에 나타나지 않는다.

유닛의 장착 백팩 필드를 비우면 미장착이다. `SampleUnarmedBackpack`으로 바꾸면 백팩은 장착하지만 추가 무장은 없다. 교체는 전투 시작 전 설정이며, Play 도중 교체해 탄약을 다시 채우는 기능은 제공하지 않는다.

## 새 백팩 만들기

Project 창의 `Create > MechaXCOM > Backpack Data`로 생성하거나 샘플을 복제한다. 복제한 에셋의 **백팩 ID**는 다른 값으로 지정한다. ID의 프로젝트 전체 중복 검사는 별도 기능이므로 작성자가 관리한다.

| Inspector 항목 | 의미 |
|---|---|
| 백팩 ID / 이름 / 설명 | 식별자와 표시 정보 |
| 백팩 자체 중량 (톤) | 포함 무기 중량을 제외한 백팩·장착대 중량 |
| 포함 무장 | 이 백팩에 고정된 WeaponData 하나. 비우면 무장 없음 |
| 모델 프리팹 (선택) | 외형 정의 참조. 현재 자동 부착 기능은 없음 |

포함 무장은 BackpackData에서 정의한다. 유닛 장착 설정에서는 포함 무장만 별도로 교체하지 않고 백팩 에셋을 교체한다. 다른 무기 성능이 필요하면 WeaponData도 복제해서 연결하는 편이 안전하다. 동일 WeaponData를 손 무기나 다른 백팩과 공유한 상태에서 그 에셋의 피해·사거리 등을 수정하면 모든 참조 장비의 정의가 함께 바뀐다.

## 탄약·공격·경계 규칙

- 원거리 백팩의 피해·명중률·사거리·발사 AP·장탄 수는 포함 무기의 WeaponData를 따른다. 샘플은 빔 무기의 유한 에너지 팩 방식이다.
- 전투 시작 시 탄창·팩 하나가 장전되며, 예비 탄약은 항상0이고 재장전할 수 없다. WeaponData에 예비 개수·재장전 AP가 설정되어 있어도 백팩 슬롯에서는 사용하지 않는다. 같은 데이터를 쓰는 손 무장의 재장전 설정은 유지된다.
- 실제 발사하면 명중·빗나감 모두1발을 소비한다. 미리보기·잘못된 공격·경계사격 Skip은 소비하지 않는다.
- 턴 변경, AP 회복, 재활성화, 손 무기 파지 전환으로 잔탄이 복구되지 않는다. 유닛별·손 슬롯별·백팩별 잔탄은 독립적이다.
- 백팩은 손의 양손 파지 보너스를 받지 않으며, 팔 파괴만으로 사용 불가가 되지 않는다. 유닛이 Critical/Destroyed/Ejected이면 기존 공통 규칙에 따라 공격할 수 없다.
- 원거리 백팩은 기존 `Overwatch` 무기 선택 목록에서도 선택할 수 있다. Fire는 탄약을 소비하고 Skip은 유지한다. 마지막 탄약을 쓰면 경계를 해제하고 대기하던 적 이동을 정상 재개한다.
- 탄약이 떨어진 백팩은 선택 가능한 공격 메뉴가 열려 있을 때 이름과 잔탄0으로 표시되지만 사격할 수 없다. 유닛에 가능한 공격이 하나도 없으면 Attack 메뉴 자체도 열리지 않는다.
- 적 AI도 사용 가능한 백팩 무장을 기존 공격 경로로 사용한다. 소진된 백팩을 재장전하지 않으며 다른 사용 가능한 손 무기를 사용하거나 대기한다. 전용 화력 배분 AI는 추가하지 않았다.

명중률 상한99%, 부위 조준, 장갑 상성, 파일럿 능력치, 치명타 등은 손 무기와 같은 공통 계산을 사용한다.

## 중량과 현재 범위

```text
총 장착 중량
= 왼손 무기 본체 + 왼손 장전·예비 탄약
+ 오른손 무기 본체 + 오른손 장전·예비 탄약
+ 백팩 자체 중량 + 백팩 포함 무기 본체 + 백팩 장전 탄약 1개
```

양손 무기는 한 손 슬롯에만 지정하므로 한 번만 계산한다. 같은 WeaponData를 손과 백팩에서 함께 참조하면 서로 다른 실제 장비이므로 각 슬롯에 대해 계산한다. 기체 자체 중량은 위 장착 중량에 포함하지 않는다.

두 샘플의 백팩 자체 중량0은 연결 검증용 미조정 값이다. 현재 참조한 고정 원거리 무기의 중량도0이다. 실제로 무거운 백팩을 만들려면 백팩 자체 중량과 포함 무기 중량을 각각 설정해야 한다. 기존 무기 에셋의 밸런스를 바꾸지 않기 위해 샘플 생성 과정에서 이 값을 임의로 올리지 않았다.

총 장착 중량은 기체의 장착 중량 한도와 비교한다. 한도0은 제한 미설정이며, 양수이면 한도 초과 장착과 전투 시작을 차단한다. 한도와 같은 중량은 허용한다. Inspector와 장착 API는 초과 변경을 거부한다. 기존 에셋 수정으로 이미 초과된 설정은 장비 해제를 통해 단계적으로 복구할 수 있지만 정상 한도까지 줄이기 전에는 출격할 수 없다. 전투 시작 시 한 기체라도 초과하면 전투 전체를 시작하지 않으며 Console에 원인이 표시된다.

무기 본체와 만탄 탄창·팩 중량은 WeaponData에서 따로 지정한다. 손 무기의 예비 개수는 기체별 UnitWeaponLoadout에서 선택하고 백팩 예비는 항상 0이다. 전투 중 사용량에 따른 중량 감소나 중량에 따른 AP당 이동거리 변경은 포함하지 않는다. 실제 백팩 모델의 자동 장착·장착점·애니메이션과 백팩 부위 HP도 추가하지 않았다. 자세한 설정은 [탄약 가이드](weapon-ammo.ko.md)를 참고한다.

## 검증 결과

2026-11-04 기준 테스트 복제본에서 전체 EditMode 726/726, 그래픽 PlayMode 380/380이 통과했다. 실패·건너뜀은 0이다. 샘플 에셋 재읽기와 기존 손 무장 전투, 백팩 사격·잔탄·재장전 차단·경계·AI·실제 메뉴 입력을 검증했다. 기존 저장 씬에 백팩을 자동 배치하지 않았다.

장착 중량 제한 검증에는 한도0/동일 중량/소수점 합산/실제 초과, Inspector 다중 편집과 Undo, 초과 장비 단계별 해제, 직접 초기화와 전투 전체 사전 차단·재시도가 포함된다.
