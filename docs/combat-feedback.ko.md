# 공격 결과 팝업

플레이어·적 AI·경계사격은 같은 공격 결과 표시를 사용합니다. 근접, 원거리, 직사 폭발 추가 부위 피해, 곡사, 엄폐물 공격에 적용합니다.

공격 AP·탄약 지불과 HP·부위 파괴 계산은 즉시 끝납니다. 그 다음 대상 위에서 약 **0.8초** 동안 결과를 표시합니다. **0.15초 동안 아래에서 위로 살짝 튀어 오르고 → 0.5초 동안 완전히 보이는 상태로 정지 → 0.15초 동안 제자리에서 페이드아웃**합니다. 올라올 때 목표 높이를 조금 넘었다가 안착하는 움직임을 사용하며, 정지/페이드 단계에는 추가로 올라가지 않습니다. 이 동안 다음 전투 행동·턴 종료·다음 적의 행동·경계의 다음 사수 및 이동 재개를 기다립니다. 카메라 조작은 유지됩니다. 마지막 적을 파괴한 공격도 팝업 종료 뒤 전투 종료를 판정합니다.

| 표시 | 의미 |
|---|---|
| Body -800 | 피격 부위명과 실제 HP 감소량 |
| CRITICAL! / Body -1000 | 치명타 문구와 부위별 피해, 노란색 강조 |
| MISS | 빗나감, 흰색 표시 |
| -100 | 엄폐물도 피해 숫자만 표시 |

한 기체가 여러 부위를 맞으면 각 부위명과 피해 숫자를 한 팝업에 줄별로 표시합니다. HIT·COVER·DESTROYED 문구는 붙이지 않습니다. 곡사로 여러 기체/엄폐물이 맞으면 동시에 표시합니다. 발사 전 플레이어 시야에서 미탐지였던 적의 이름·위치·피해는 표시하지 않으며, 아군은 표시합니다. 파괴된 기체의 팝업은 공격 직전 위치에 남습니다.

조준창·디버그의 공통 부위명은 **Head / Body / L.Arm / R.arm / L.Leg / R.Leg / C.Pit**를 유지합니다. 이미지 파일 자체에 인쇄된 한글은 바꾸지 않습니다. HP·AP·Ammo의 기존 Oxanium 적용은 유지합니다.

## 시간 조절

`BattleSceneController`가 있는 오브젝트의 `CombatFeedbackPresenter` → **팝업 표시 시간**에서 조절합니다. 기본 0.8초이며 0.05~3초 범위입니다. 시간 배율과 독립적으로 동작합니다.

전체 시간을 바꾸면 등장·정지·퇴장의 시간도 같은 비율로 바뀝니다. 기본 시간에서는 정지 구간이 0.5초입니다.

표시기는 두 저장 씬에서 런타임에 자동 연결합니다. 영구적인 Inspector 설정이 필요하면 Edit Mode에서 같은 오브젝트에 `CombatFeedbackPresenter`를 미리 추가하고 시간을 지정한 뒤 저장하세요. 실행 중에만 바꾼 값은 Play 종료 시 유지되지 않습니다. 카메라가 없는 순수 전투 로직에는 표시 대기를 만들지 않습니다. 표시기를 비활성화하거나 제거하면 남은 팝업과 대기를 해제합니다.

전투 결과는 `CombatSystem.AttackFeedback`으로 전달하고, 표시기는 계산된 문자열과 세계 좌표만 보관합니다. 팝업을 표시하면서 피해를 다시 계산하거나 AP·탄약을 다시 소모하지 않습니다. 저장 씬과 기체·무기 데이터, 모델, 카메라 설정은 변경하지 않았습니다.

검증: 2026-11-08 테스트 복제본 전체 EditMode 929/929, 그래픽 PlayMode 431/431 통과. 실패·건너뜀 0. 두 저장 씬의 자동 연결, 실제 메뉴 입력, 영어 포맷, 근접 치명타, 시간 배율 0, AI·경계·다중 대상·미탐지 보호와 파괴 후 전투 종료를 포함합니다.
