# Field Command · 전투 UI 프로토타입

`battle-ui-prototype.html`을 브라우저에서 열면 실행됩니다. 이미지·스타일·스크립트를 포함한 단일 파일이므로 이 파일만 옮겨도 됩니다. 설치·빌드·외부 네트워크 연결이 필요하지 않습니다.

수정용 원본은 `index.html`입니다. 원본을 옮길 때는 HTML, CSS, JS, battlefield.png를 함께 복사하세요. 단일 파일 배포본은 원본 변경 시 다시 내보내야 합니다.

시안의 레이아웃을 HTML 요소로 구성했습니다. 기체·무기·부위 선택, 이동/AP 소모, 사격/잔탄 소모/부위 HP 표시, 재장전, 백팩 재장전 제외, 경계 상태, 긴급탈출 확인, 턴 종료/AP 회복, ESC 선택 취소와 초기화를 시연할 수 있습니다. 데스크톱과 작은 화면을 지원합니다.

Unity와 연결된 전투 구현이 아닌 UI 검토용 시연입니다. 장비/파일럿/내구도/중량/피해/명중률은 예시이며 실제 프로젝트 데이터를 읽지 않습니다. 이동 지형·시야·LOS·엄폐 방향·정확한 그리드·AI·경계 반응 사격·카메라 회전은 재현하지 않습니다. 휠은 배경 확대만 시연합니다. 적 턴은 안내 후 아군 AP를 회복하는 간략한 흐름입니다.

수정 위치:

- `index.html`: 영역 구성
- `style.css`: 색상·배치·반응형 크기
- `app.js`: 예시 데이터와 상호작용
- `battlefield.png`: 생성한 전장 배경

Unity Assets 및 기존 씬·설정은 변경하지 않습니다.

검증: Node 구문 검사 및 실제 app.js를 격리된 DOM 대역에서 실행하여 선택·조준·사격/AP/탄약/HP·재장전·턴 회복·백팩 경계·탈출 확인/취소/재열기·이동·ESC·초기화와 로컬 리소스를 확인했습니다. 자동 브라우저 미리보기는 로컬 파일 URL 정책으로 차단되어 실제 화면 렌더링 및 반응형 배치는 브라우저에서 검증하지 못했습니다.
